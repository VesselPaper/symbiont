# 02 系统接口设计文档

## 一、接口总览

说明：本文件是接口权威。实现偏离必须同步本文件。REST 接口以 `/openapi.json` 为准。

| 类别 | 说明 |
|---|---|
| 客户端内部 | Autoload 单例、组件、EventBus 信号 |
| 客户端 ↔ 服务器 | REST API（v1） |
| 数据管道 | SQL → SQLite → JSON |
| 存档格式 | Schema v1 |

## 二、客户端内部接口

### 2.1 Autoload 单例

| 单例 | 职责 | 关键 API |
|---|---|---|
| EventBus | 事件总线 | 信号 + `log_event(name, data)` |
| GameManager | 全局状态机 | `start_new_game() / record_sacrifice() / set_flag() / add_monster_limb() / try_consume_monster_limb() / to_dict() / from_dict() / play_sfx(name, volume_db=0, pitch=1)`；`has_weapon` 跨层保留铁剑，`has_steam_boots` 跨层保留二段跳，二者都进存档；窗口模式下在子节点挂 AudioDirector |
| DataDB | 数据访问 | `get_item / get_enemy / get_npc / get_dialogue / get_ending / get_sacrifice / table()` |
| SaveSystem | 存档 | `save(slot) / load(slot) / has_save(slot) / delete_slot(slot)`；`pending_player` 暂存读档玩家数据，`apply_pending_player(player)` 在目标关卡落地 |
| Settings | 设置 | `load_settings() / save_settings()`；`master_volume / bgm_volume / sfx_volume` 三档 0~1，`set_master/bgm/sfx_volume()` 钳制后发 `audio_changed`；主音量走 Master 总线 |
| Network | 网络 | `configure(base, token) / report_event() / flush_events() / push_save() / pull_save()` |

### 2.2 EventBus 信号

`player_hurt / player_died / enemy_killed / boss_encounter_started / boss_defeated / player_moved_between_floors / item_picked / sacrifice_done / body_part_modified / marker_triggered / save_loaded / save_failed / dialogue_started / dialogue_finished / ending_reached / game_over`。

`marker_triggered(marker_id)`：任务光点被玩家接触时触发。教学关改成按位置判定后（M4-21）场景里已没有光点，事件本身保留，供其它关卡/监听方接入。

### 2.3 组件接口

| 组件 | 说明 |
|---|---|
| dialogue.gd | `play(dialogue_id)` 从 DataDB 读台词，K 键快进/逐条，`next_id` 顺序链；`abort()` 强制收尾；信号 `dialogue_started / dialogue_finished` 成对，重播/死亡/节点释放都会先发上一段的 finished |
| dialogue_locator.gd | `resolve(owner, controller, explicit_path)` 按显式路径→控制器 `Dialogue`→场景根/分组→全局兜底解析；`is_dialogue / is_playing / is_active / is_line_done` 统一查询；兜底要求 `is_line_done`，排除 AudioStreamPlayer |
| interaction_prompt.gd | `create(parent, text, position, size, font_size, color, outline, z, shadow)` 统一世界空间 K 提示的字体/描边/阴影/居中，不负责范围判定 |
| tutorial.gd | 新手教程状态机，事件驱动 + 每帧检查；UI 契约 `show_objective(step, text, world_pos) / set_active_step(step)` 与临时提示 `show_bubble / hide_bubble / set_bubble_position` |
| tutorial_bubble.gd | 头顶跟随气泡，世界空间 Node2D |
| objective_hud.gd | 教学目标刻字，世界坐标 Node2D（z=6）：`show_objective(step, text, world_pos)` 每环刻一句、`set_active_step(step)` 当前句亮/其余暗（-1 全暗），`show_bubble / hide_bubble / set_bubble_position` 只收「获得铁剑 / 教程完成」这类临时提示；`TEXT_OFFSET=-88`、临时提示再上移 30px；`hide_bubble` 不再藏整块目标文字 |
| altar.gd | 祭坛献祭，`try_sacrifice() -> bool`，无肢体返回 false，对话期间不响应 K；手上有真 HE 骨片时改走 `try_restore() -> bool`，只开 `true_he_unlocked`，不计献祭数；新手祭坛 `allow_refuse` 打开时 R 发 `refuse_requested`，不直接结算 |
| player.gd | `has_weapon` 控制攻击解锁，未解锁按 J 无效；`_ready` 从 `GameManager.has_weapon` 继承，拾取时写回；`has_steam_boots` 控制空中第二跳（`try_air_jump()`，每次离地一次，落地重置），**只给能力不改角色外观**（M4-20 起拿到靴子身上不挂任何新东西）；`apply_faction(faction)` 只改阵营装束（工程师蒸汽靴/背罐、祭司污化腿）；横砍/下劈经 `GameManager.play_sfx` 出声 |
| audio_director.gd | 音频总监，由 GameManager 在窗口模式实例化，不新增 autoload：BGM 按状态/场景切 `bgm_menu/tutorial/floor1/floor2/floor3/combat/ending` 七首 22.9～38.9s 循环，另有 `amb_menu/floor1/floor2/floor3` 环境层；`MUSIC_TRACKS` 的 `music_transition/music_sacrifice/music_death` 是一次性音乐层，走 `play_music(name, volume_db)`，播完由 `Music.finished` 把 BGM 抬回；`boss_encounter_started` 切战斗曲、`boss_defeated` 切回第三层，离开第三层或玩家死亡也清战斗标记；SFX 目录 44 个，播放器池 14 个；`play_sfx(name, volume_db=0, pitch=1)` 未知名字静默返回；BGM/SFX/音乐层基准跟随 Settings 档位换算 dB，对话时 BGM 再压 9dB、结束恢复；无头模式不创建，避免 dummy AudioServer 退出占用 |
| faction_npc.gd | 第二层阵营 NPC：`offer_id / confirm_id / after_id` 从数据表读；第一次提议播完才接受确认，选择提交给关卡 `choose_faction()` |
| faction_seal.gd | 阵营封印门：`open(faction)` 关闭碰撞并下沉；没选前挡路 |
| 可受击实体（slime / spore / dummy / boss） | `damageable` 组 + `take_damage(amount)`；可选 `apply_knockback(source_pos, strength)` 与 `knockback_weight`（越大越难被推，玩家反作用力越大） |
| gatekeeper_boss.gd | 守门者：`activate() / take_damage() / apply_knockback() / is_dead()`；激活发 `EventBus.boss_encounter_started`，死亡发 `EventBus.boss_defeated` |
| boss_exit_door.gd | 第三层出口门：`open()` 关闭碰撞并下沉，`is_open()` 供结局判定 |
| return_shaft.gd | 第三层入口旧货梯：只在 `boss_defeated` 后显示「K 回起点」，调楼层 `return_to_start()`，写 `true_he_return` 后回教学关 |
| origin_relic.gd | 二周目起点骨片：碰到写 `true_he_relic`，发 `item_picked("origin_relic", 1)`，播 `true_he_relic_pickup` |
| ending_screen.gd | 复用结局画面：`show_ending(id)` 从 `endings` 表读名/说明，黑场 + 引语，按 K 发 `restart_requested`，不碰 GameManager |
| main.gd | 主菜单：开始新游戏重置后进教学关；继续读最近存档并按 `current_floor` 回层；退出；黑场切场景 |
| pause_menu.gd | Esc 暂停菜单：槽位 1 保存/读档/返回；暂停整棵树，读档跨层时先解除暂停再切场景；M4-11 增加背景音乐/音效两条滑条，拖动实时生效、松手写 `settings.cfg` |
| game_hud.gd | 游戏 HUD：读玩家 `hp` 画五枚骨片，显示 `sacrifice_count` 与 `item_picked` 短提示；不改数值 |

对话 UI 契约：`show_box() / hide_box() / set_speaker() / set_text() / set_continue_hint(show)`。

待定稿：state_machine / health / damageable / hookshot / inventory。

### 2.4 场景切换

`get_tree().change_scene_to_file(path)`；当前没有全局 SceneChanger，参数通过 GameManager 旗标传递。

启动链：`scenes/main/main.tscn`（主菜单）→ 开始新游戏 → 教学关 → `floor1.tscn` → `floor2.tscn` → `floor3.tscn`。每层用 CanvasLayer 黑场 + 层名，`change_scene_to_file` 切换；门缝判定会等当前层门对话播完再切。结局画面统一由 `scenes/ui/ending_screen.tscn` 生成，按 K 发 `restart_requested`，由各关卡决定回主菜单还是教学关起点；新手拒绝结局回主菜单。真 HE 走反向链：第三层货梯 → 教学关（`true_he_return`）→ 祭坛归还，`current_floor` 记为 `start`。继续游戏读最近存档后按 `current_floor` 直接回对应层。

## 三、REST API（v1）

| 方法 | 路径 | 说明 | 状态 |
|---|---|---|---|
| GET | /api/v1/health | 探针 | ✅ |
| POST | /api/v1/auth/register | 注册 | M2 |
| POST | /api/v1/auth/login | 登录，返回 token | M2 |
| GET | /api/v1/saves/{slot} | 拉远程存档 | M2 |
| PUT | /api/v1/saves/{slot} | 推远程存档 | M2 |
| POST | /api/v1/events | 批量埋点 | M2 |
| GET | /api/v1/leaderboard | 排行榜 | M2 |

鉴权：`Authorization: Bearer <token>`。错误码：`{"detail": "..."}`。
WebSocket 不做：单机无实时需求。

## 四、数据管道

`database/game_data/*.sql` → `build_game_data.py` → `.db` → `db_export.py` → `client/data/<表>/<id>.json` + `<表>_index.json`。

表清单：items / enemies / npc / dialogues / endings / sacrifices。字段以 `database/game_data/schema.sql` 为准。

## 五、存档 Schema v1

```json
{
  "version": 1,
  "saved_at": "2026-09-...",
  "game_progress": { "sacrifice_count": 1, "monster_limb_count": 2, "current_floor": "start", "faction": "", "flags": {} },
  "player": { "position": [300.0, 646.0], "hp": 4, "has_weapon": true, "has_steam_boots": false },
  "inventory": { "monster_limb_count": 2 },
  "levels": { "scene": "res://scenes/world/test_arena.tscn" }
}
```

`player.position` 用 global_position，读档时先暂存，目标关卡 `_ready` 再落地；`levels.scene` 记录存档时场景，供主菜单继续/排错用。
