# 02 系统接口设计文档

## 一、接口总览

说明：本文件是接口权威。实现偏离必须同步本文件。REST 接口以 `/openapi.json` 为准。

| 类别 | 说明 |
|---|---|
| 客户端内部 | Autoload 单例、组件、EventBus 信号 |
| 客户端 ↔ 服务器 | REST API（v1） |
| 数据管道 | SQL → SQLite → JSON |
| 存档格式 | Schema v1 |

## 二、客户端内部接口

### 2.1 Autoload 单例

| 单例 | 职责 | 关键 API |
|---|---|---|
| EventBus | 事件总线 | 信号 + `log_event(name, data)` |
| GameManager | 全局状态机 | `start_new_game() / record_sacrifice() / set_flag() / add_monster_limb() / try_consume_monster_limb() / to_dict() / from_dict()` |
| DataDB | 数据访问 | `get_item / get_enemy / get_npc / get_dialogue / get_ending / get_sacrifice / table()` |
| SaveSystem | 存档 | `save(slot) / load(slot) / has_save(slot)` |
| Settings | 设置 | `load_settings() / save_settings()` |
| Network | 网络 | `configure(base, token) / report_event() / flush_events() / push_save() / pull_save()` |

### 2.2 EventBus 信号

`player_hurt / enemy_killed / item_picked / sacrifice_done / body_part_modified / marker_triggered / save_loaded / save_failed / dialogue_started / dialogue_finished / ending_reached / game_over`。

`marker_triggered(marker_id)`：引导光点被玩家接触时触发。教学改用单个光点后，触发后由 tutorial 调 `move_to` 飞向下一目标，字段保留兼容其它监听方。

### 2.3 组件接口

| 组件 | 说明 |
|---|---|
| dialogue.gd | `play(dialogue_id)` 从 DataDB 读台词，K 键快进/逐条，`next_id` 顺序链；信号 `dialogue_started / dialogue_finished` |
| tutorial.gd | 新手教程状态机，事件驱动 + 每帧检查；UI 契约 `show_bubble / hide_bubble / set_bubble_position` |
| tutorial_bubble.gd | 头顶跟随气泡，世界空间 Node2D |
| altar.gd | 祭坛献祭，`try_sacrifice() -> bool`，无肢体返回 false，对话期间不响应 K |
| player.gd | `has_weapon` 控制攻击解锁，未解锁按 J 无效 |

对话 UI 契约：`show_box() / hide_box() / set_speaker() / set_text() / set_continue_hint(show)`。

待定稿：state_machine / health / damageable / hookshot / inventory。

### 2.4 场景切换

`SceneChanger.change_scene(path, params)`

## 三、REST API（v1）

| 方法 | 路径 | 说明 | 状态 |
|---|---|---|---|
| GET | /api/v1/health | 探针 | ✅ |
| POST | /api/v1/auth/register | 注册 | M2 |
| POST | /api/v1/auth/login | 登录，返回 token | M2 |
| GET | /api/v1/saves/{slot} | 拉远程存档 | M2 |
| PUT | /api/v1/saves/{slot} | 推远程存档 | M2 |
| POST | /api/v1/events | 批量埋点 | M2 |
| GET | /api/v1/leaderboard | 排行榜 | M2 |

鉴权：`Authorization: Bearer <token>`。错误码：`{"detail": "..."}`。
WebSocket 不做：单机无实时需求。

## 四、数据管道

`database/game_data/*.sql` → `build_game_data.py` → `.db` → `db_export.py` → `client/data/<表>/<id>.json` + `<表>_index.json`。

表清单：items / enemies / npc / dialogues / endings / sacrifices。字段以 `database/game_data/schema.sql` 为准。

## 五、存档 Schema v1

```json
{
  "version": 1,
  "saved_at": "2026-09-...",
  "game_progress": { "sacrifice_count": 1, "current_floor": "floor_1", "faction": "", "flags": {} },
  "player": {},
  "inventory": {},
  "levels": {}
}
```

player / inventory / levels 在 M1/M2 定稿后同步本文件。
