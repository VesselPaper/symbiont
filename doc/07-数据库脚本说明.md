# 07 数据库脚本说明

## 一、数据库概览

| 层 | 用途 |
|---|---|
| MySQL 8（服务器） | 动态数据：账号 / 远程存档 / 埋点 / 排行榜 |
| SQLite（游戏内容库） | 静态数据：物品 / 敌人 / 对话 / 结局 / 献祭，数据驱动 |

## 二、脚本清单

| 脚本 | 库 | 用途 | 位置 |
|---|---|---|---|
| schema.sql | MySQL 8 | users/saves/events/leaderboard 建表 | database/schema.sql |
| seed.sql | MySQL 8 | 初始数据 | database/seed.sql |
| schema.sql | SQLite | 游戏内容 6 表建表 | database/game_data/schema.sql |
| seed.sql | SQLite | 游戏初始内容 | database/game_data/seed.sql |

## 三、执行方式

| 方式 | 命令 |
|---|---|
| docker 自动执行 | 容器启动时自动建表/播种 |
| 手动 MySQL | mysql -u root -p < schema.sql |
| 数据管道 | tools/build_game_data.py |

## 四、服务器表结构

| 表 | 关键字段 | 说明 |
|---|---|---|
| users | id, username(唯一), password_hash, created_at | 账号 |
| saves | id, user_id, slot, save_data(JSON), updated_at | 远程存档 |
| events | id, user_id(可空), event, payload(JSON), created_at | 埋点 |
| leaderboard | id, board, user_id, score, meta(JSON), created_at | 排行榜 |

## 五、游戏内容库表结构

| 表 | 关键字段 | 说明 |
|---|---|---|
| items | id, name, type, stats(JSON), obtain, flags(JSON) | 物品/道具 |
| enemies | id, name, hp, speed, behavior, attack_damage, drops(JSON) | 敌人 |
| npc | id, name, faction, location | NPC |
| dialogues | id, npc_id, lines(JSON), next_id, branch | 对话 |
| endings | id, name, condition, weight | 结局 |
| sacrifices | id, part, route, effect(JSON) | 献祭改造 |

## 六、枚举说明

| 字段 | 枚举 |
|---|---|
| items.type | weapon / shield / consumable / upgrade / quest / body_part |
| enemies.behavior | patrol / ranged / dive / boss |
| endings.id | refuse_die / human / transformed / true_he |
