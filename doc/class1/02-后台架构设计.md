# 02 后台架构设计

课程：软件工程 ｜ 组号：2 组 ｜ 项目：共生之缚 Symbiont

配套图：`uml/`（后端组件图、部署图、后端类图、登录推档时序图）

## 一、后端定位

轻量后端，单机为主、联网可选。客户端离线优先，联网后同步。

| 职责 | 说明 |
|---|---|
| 账号 | 注册、登录、token |
| 远程存档 | 同步客户端存档 JSON |
| 统计埋点 | 批量接收游戏事件 |
| 排行榜 | 查询排序 |

## 二、分层

| 层 | 内容 |
|---|---|
| 接入层 | Nginx 反代 /api 到 server，托管 Web 版静态资源 |
| 业务层 | FastAPI：路由（接收/校验）→ 服务（业务规则）→ 数据访问（SQLAlchemy） |
| 数据层 | MySQL 8：users / saves / events / leaderboard |

## 三、REST 接口

| 方法 | 路径 | 说明 | 鉴权 |
|---|---|---|---|
| GET | /api/v1/health | 健康探针 | 无 |
| POST | /api/v1/auth/register | 注册 | 无 |
| POST | /api/v1/auth/login | 登录，返回 token | 无 |
| GET | /api/v1/saves/{slot} | 拉远程存档 | Bearer token |
| PUT | /api/v1/saves/{slot} | 推远程存档 | Bearer token |
| POST | /api/v1/events | 批量埋点 | Bearer token（可空） |
| GET | /api/v1/leaderboard | 排行榜 | 无 |

错误码 `{"detail": "..."}`（FastAPI 默认）。WebSocket 不做：单机无实时需求。

## 四、数据表

| 表 | 核心字段 | 说明 |
|---|---|---|
| users | id, username 唯一, password_hash, created_at | 账号 |
| saves | id, user_id→users, slot, save_data JSON, updated_at | 每用户每槽一条 |
| events | id, user_id（可空）, event, payload JSON, created_at | 埋点 |
| leaderboard | id, board, user_id→users, score, meta JSON, created_at | 排行榜 |

存档对齐 Schema v1：`{version, saved_at, game_progress{sacrifice_count, current_floor, faction, flags}, player, inventory, levels}`。

## 五、部署

| 容器 | 镜像 | 职责 |
|---|---|---|
| mysql8 | mysql:8 | 数据持久化 |
| server | Dockerfile.server | FastAPI + uvicorn :8000 |
| nginx | Dockerfile.game-web + nginx.conf | 托管 Web 版 + 反代 /api |

`docker compose up -d` 一键拉起。
