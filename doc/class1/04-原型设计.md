# 04 原型设计

课程：软件工程 ｜ 组号：2 组 ｜ 项目：共生之缚 Symbiont

配套图：`uml/系统UI原型.png`

## 一、原型工具

| 工具 | 定位 | 用途 |
|---|---|---|
| Figma（主） | 在线线框，多人协作 | 主菜单/HUD/对话/存档等界面 |
| Axure RP（备） | 交互细节、条件分支 | 存档读档、献祭计数联动等演示 |
| Godot 编辑器 | 实际效果 | 手感、粒子、演出以游戏内为准 |

流程：Figma 画线框 → 组内评审 → 开发实现 → 游戏内效果为准。

## 二、界面原型总览

![系统UI原型](uml/系统UI原型.png)

| 界面 | 关键内容 | 状态 |
|---|---|---|
| ① 主菜单 | 开始/继续/设置/退出，有存档时"继续"亮起 | ⏳ M1 |
| ② 游戏内 HUD | 血条 · 献祭计数/肢体数 · 按键提示 | ⏳ M1 |
| ③ 对话界面 | 说话人 + 打字机正文 + 按 K 继续，锁输入 | ✅ M1 |
| ④ 教程气泡 | 头顶提示 + 引导光点 | ✅ M1 |
| ⑤ 祭坛献祭 | 按 K 献祭，消耗肢体、计数 +1 | ✅ M1 |
| ⑥ 存档界面 | 3 槽位：楼层/献祭数/时间 | ⏳ M1 |

界面上每个字段都对应 03 文档的数据项（如 HUD"献祭 ✦ 2"= sacrifice_count；存档槽"第 2 层 · 献祭 3"= current_floor + sacrifice_count + saved_at）。原型定位置，数据定内容。

## 三、关键交互

1. 主菜单 → 开始/继续 → 进入游戏；
2. HUD 随状态实时更新；
3. 对话：触发 → 锁输入 → 打字机 → 按 K → 解锁；
4. 献祭：靠近提示 → 按 K → 计数 +1；
5. 存档：选槽 → 保存/读取/覆盖确认。
