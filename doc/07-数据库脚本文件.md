# 数据库脚本文件

> 项目：《共生之缚》（Symbiont）
> 《软件工程》课程设计 · 交付文档 7
> 版本：v1.0

## 1. 说明

本交付物为系统数据库脚本，正文位于仓库 `database/` 目录：

| 文件 | 说明 |
|---|---|
| `database/schema.sql` | 建库建表脚本（MySQL 8，utf8mb4）：8 张核心表 + 索引 + 外键 |
| `database/seed.sql` | 初始数据：示例关卡（主地牢 / 跑酷 / Boss）、示例公告 |

## 2. 数据库概览

- 数据库名：`symbiont`
- 字符集：`utf8mb4 / utf8mb4_unicode_ci`（支持中文与 Emoji）
- 引擎：InnoDB（事务 + 外键）

## 3. 表清单

| # | 表名 | 用途 | 关键字段 |
|---|---|---|---|
| 1 | users | 账号（角色 / 状态） | username, password_hash, role, status |
| 2 | user_profiles | 用户扩展档案 | total_play_seconds, total_deaths, last_login_at |
| 3 | saves | 云存档（冲突检测 + 防篡改） | slot, version, data_json, checksum |
| 4 | leaderboard_entries | 排行榜（3 维度 + 关卡分榜） | metric_type, level_id, value, stars |
| 5 | levels | 关卡配置（JSON 数据 + AI 标记） | level_key, type, difficulty, data_json, ai_generated |
| 6 | announcements | 公告 | title, content, enabled |
| 7 | player_events | 行为事件埋点（统计数据源） | event_type, payload_json |
| 8 | admin_logs | 管理操作日志 | admin_id, action, detail |

## 4. 使用方式

### 4.1 手动导入
```bash
mysql -u root -p < database/schema.sql
mysql -u root -p < database/seed.sql
```

### 4.2 Docker 方式（推荐）
```bash
docker compose up -d mysql
docker compose exec -T mysql sh -c 'exec mysql -uroot -p"$MYSQL_ROOT_PASSWORD"' < database/schema.sql
docker compose exec -T mysql sh -c 'exec mysql -uroot -p"$MYSQL_ROOT_PASSWORD"' < database/seed.sql
```

### 4.3 开发环境
后端使用 Alembic 迁移管理演进：`alembic revision --autogenerate` / `alembic upgrade head`；
`schema.sql` 与 Alembic 迁移保持同步，作为交付基线。

## 5. 说明与注意

- **管理员账号**：密码经 bcrypt 哈希，由后端启动引导创建（`scripts/create_admin.py`），不在 SQL 中明文写入；
- **示例关卡** `data_json` 为占位骨架，正式关卡由关卡编辑器 / AI 生成后经管理后台入库；
- **外键策略**：用户相关表 CASCADE（删用户连带删存档/事件）；公告创建人 SET NULL；
- **性能索引**：排行按 `(metric_type, value)`、事件按 `(user_id, created_at)` / `(event_type, created_at)` 建索引。
