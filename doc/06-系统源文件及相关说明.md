# 06 系统源文件及相关说明

课程交付 6 ｜ 组号：2 组 ｜ 项目：共生之缚 Symbiont

## 一、仓库概览

| 项 | 内容 |
|---|---|
| 仓库 | github.com/VesselPaper/symbiont |
| 分支 | main（保护）+ feature/PR 流程 |
| CI | GitHub Actions（数据管道 / server pytest / Godot 无头） |

## 二、目录结构

| 目录 | 职责 |
|---|---|
| client/ | Godot 游戏客户端（scenes / scripts / autoload / data） |
| server/ | FastAPI 后端（app / tests） |
| database/ | MySQL schema/seed + 游戏内容库 SQL |
| tools/ | 数据管道脚本（build / export） |
| deploy/ | docker-compose + Dockerfile + nginx.conf |
| scripts/ | 构建/测试/导出 PowerShell 脚本 |
| doc/ | 课程文档与课堂作业 |
| art/ | 美术素材 |
| webadmin/ | 管理看板（stretch） |
| .github/ | CI 工作流 |

## 三、构建与运行入口

| 脚本 | 用途 |
|---|---|
| scripts/setup.ps1 | 初始化 |
| scripts/test_all.ps1 | 全量测试 |
| scripts/run_server.ps1 | 起后端 |
| scripts/export_web.ps1 | 导出 Web 版 |
| scripts/export_desktop.ps1 | 导出桌面版 |
| tools/build_game_data.py | SQL → SQLite |
| tools/db_export.py | SQLite → JSON |
