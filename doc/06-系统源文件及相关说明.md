# 06 系统源文件及相关说明

## 一、仓库概览

| 项 | 内容 |
|---|---|
| 仓库 | github.com/VesselPaper/symbiont |
| 分支 | main（保护）+ feature/PR 流程 |
| CI | GitHub Actions（数据管道 / server pytest / Godot 无头） |

## 二、目录结构

| 目录 | 职责 |
|---|---|
| client/ | Godot 游戏客户端（scenes / scripts / autoload / data） |
| client/tests/ | 无头验证脚本：smoke / floor1 / transition；截图脚本：screenshot / tour_shots / arena_shots / player_anim_shots；模型展示场景 art_stage.tscn |
| client/assets/ | 字体（Noto CJK）与 shader；场景美术全部代码生成，不依赖图片 |
| client/shots/ | 开发期截图（教学关、第一层、玩家动作、怪物与道具模型） |
| server/ | FastAPI 后端（app / tests） |
| database/ | MySQL schema/seed + 游戏内容库 SQL |
| tools/ | 数据管道脚本（build / export） |
| deploy/ | docker-compose + Dockerfile + nginx.conf |
| scripts/ | 构建/测试/导出 PowerShell 脚本 |
| doc/ | 课程文档与课堂作业 |
| art/ | 美术素材 |
| webadmin/ | 管理看板（stretch） |
| .github/ | CI 工作流 |

## 三、构建与运行入口

| 脚本 | 用途 |
|---|---|
| scripts/setup.ps1 | 初始化 |
| scripts/test_all.ps1 | 全量测试 |
| scripts/run_server.ps1 | 起后端 |
| scripts/export_web.ps1 | 导出 Web 版 |
| scripts/export_desktop.ps1 | 导出桌面版 |
| tools/build_game_data.py | SQL → SQLite |
| tools/db_export.py | SQLite → JSON |
| client/tests/smoke_test.gd | 无头冒烟：autoload / GameManager / DataDB |
| client/tests/floor1_test.gd | 第一层结构验证：地形 / 触发器 / 剧情数据 |
| client/tests/transition_test.gd | 教学关 → 第一层门的开关与反向输入 |
| client/tests/arena_shots.gd | 教学关三处取景截图（需开窗口跑） |
| client/tests/player_anim_shots.gd | 玩家六个动作姿势特写（需开窗口跑） |
| client/tests/art_stage.tscn | 模型展示台：史莱姆/木桩/祭坛/指引光/铁剑，顺便验证史莱姆死亡掉肢体 |
