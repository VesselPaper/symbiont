## 2. 目录结构总览

```
symbiont/
├── client/          # Godot 游戏客户端（WebGL 导出）
│   ├── project.godot
│   ├── scenes/      # 场景（main/player/enemy/ui/levels/boss）
│   ├── scripts/     # GDScript（player/enemy/map/combat/level/save/net/ui）
│   ├── autoload/    # 全局单例（GameManager/SaveManager/NetClient/Audio）

│   └── data/        # 关卡 JSON 数据
├── backend/         # FastAPI 后端
│   ├── app/
│   │   ├── main.py
│   │   ├── core/    # 配置/安全(JWT)/依赖(RBAC)
│   │   ├── models/  # SQLAlchemy ORM
│   │   ├── schemas/ # Pydantic 模型
│   │   ├── api/     # 路由（auth/saves/leaderboard/stats/admin/ai/ws）
│   │   ├── services/# 业务逻辑
│   │   └── ai/      # AI 关卡生成/提示
│   ├── alembic/     # 数据库迁移
│   └── tests/       # 测试
├── admin-web/       # Vue3 管理后台（views: login/dashboard/levels/players/announcements/stats）
├── database/        # schema.sql / seed.sql（交付文档 7）
├── docker/          # Dockerfile ×3 + nginx.conf
├── scripts/         # 工具脚本（导出 WebGL / 建管理员 / 迁移种子）
└── doc/             # 课程交付文档（7 份 + 计划 + 选题）
```

## 4. 构建与运行说明

### 4.1 客户端
1. 安装 Godot 4.7，打开 `client/project.godot`；
2. 编辑器内按 F5 运行；
3. WebGL 导出：预设 Web，产物至 `client/build/`（脚本见 `scripts/`）。

### 4.2 后端
```bash
cd backend
python -m venv .venv && .venv\Scripts\activate   # Windows
pip install -r requirements.txt
uvicorn app.main:app --reload
```

### 4.3 管理后台
```bash
cd admin-web
npm install
npm run dev        # 开发
npm run build      # 构建产物 dist/
```

### 4.4 一键部署
```bash
docker compose up -d --build
```
