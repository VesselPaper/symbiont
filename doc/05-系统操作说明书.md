# 05 系统操作说明书

## 一、快速开始

| 方式 | 步骤 |
|---|---|
| Windows 桌面版 | 运行导出包，或 Godot 编辑器直接运行 |
| Web 版 | 浏览器打开游戏地址（docker 部署的 8080 端口） |
| 本地开发 | scripts/setup.ps1 初始化后编辑器运行 |

## 二、键位表

| 操作 | 键盘 | 手柄（规划） |
|---|---|---|
| 移动 | A / D | 左摇杆 |
| 跳跃 | 空格 | A |
| 攻击 | J | X |
| 下劈 | 下 + 攻击 | — |
| 交互 / 献祭 | K | Y |
| 钩锁 | L（M2 定稿） | RB |
| 暂停 / 菜单 | Esc | Start |

以 project.godot 输入映射为准。

## 三、游戏流程

1. 醒来 → 新手教学（移动/跳跃/拿剑/攻击/下劈）；
2. 猎杀怪物，拾取肢体；
3. 祭坛献祭，获得力量；
4. 二层抉择阵营（异教徒 / 工程师）；
5. 三层击败守门 Boss，结算结局。

## 四、系统功能

| 功能 | 说明 |
|---|---|
| 存档 | 3 个槽位，本地 JSON，Schema v1 |
| 设置 | 音量等（M1-06） |
| 排行榜 | 登录后查看（M2） |
| 远程存档 | 登录后自动同步（M2） |

## 五、故障与常见问题

| 问题 | 处理 |
|---|---|
| 存档丢失 | 检查 user://saves/ 目录权限 |
| 网络不可用 | 单机照常玩，联网后自动上报 |
| 设置异常 | 删除设置文件重置 |
