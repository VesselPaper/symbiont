# 05 系统操作说明书

## 一、快速开始

| 方式 | 步骤 |
|---|---|
| Windows 桌面版 | 运行导出包，或 Godot 编辑器直接运行 |
| Web 版 | 浏览器打开游戏地址（docker 部署的 8080 端口） |
| 本地开发 | scripts/setup.ps1 初始化后编辑器运行 |

## 二、键位表

| 操作 | 键盘 | 手柄（规划） |
|---|---|---|
| 移动 | A / D | 左摇杆 |
| 跳跃 | 空格 | A |
| 攻击 | J | X |
| 下劈 | 下 + 攻击 | — |
| 交互 / 献祭 | K | Y |
| 拒绝献祭 | R（仅教学祭坛，手上有肢体） | — |
| 钩锁（规划，当前未接） | — | — |
| 暂停 / 菜单 | Esc | Start |
| 演示跳关 | F2（教学关内直接进第一层） | — |

以 project.godot 输入映射为准。

## 三、游戏流程

1. 启动进主菜单：点「开始新游戏」进教学关；本地有存档时会出现「继续游戏」，读最近槽位回对应层；左下角 HUD 一直显示五枚生命骨片、献祭计数和拾取提示；
2. 醒来 → 新手教学（移动 / 跳跃 / 拿剑 / 攻击 / 下劈 / 战斗 / 献祭）；平台缝里的骨栅栏会按步骤打开，没做前一步就过不去；
3. 教学完成 → 地图右侧「第一层」门点亮 → 走进门，黑场显示「第一层 · 锈钟回廊」后进入第一层；拿到第一块肢体、还没献祭时，在教学祭坛按 R 可拒绝献祭，播 `refuse_die` 后进「拒绝献祭（死）」结局；
4. 第一层沿路打史莱姆；钟厅找守钟人对话，按 K 拉钟绳敲响锈钟，骨门下沉后才能上台阶；祭坛、断桥、遗物廊、层门各触发一段寄生体低语；走到祭坛/层门上方出现「K 调查」时，可按 K 反复听这段剧情，走开再回来仍可触发；
5. 遗物廊有孢子射手，会先鼓孢子囊蓄力再吐直线孢子弹，看到亮起要绕开；
6. 祭坛献祭：肢体飞进石碗、紫雾触须收拢、屏幕闪紫；之后角色背上会长出寄生组织，献祭越多越明显；
7. 第一层层门 → 黑场进第二层「铸炉与圣坛」；先和工程师、祭司各听一次提议，提议播完后再按 K 确认才算选边；封印门只认选中那边，选完才能去第三层；
8. 第三层「守门者之厅」：走进厅口触发守门者开场，Boss 会蓄力冲撞、跳砸放震波，半血后变快；出口门在 Boss 死前锁着，死后下沉；
9. 走进出口门结算：只做过新手那次献祭走「人类结局」，多献祭一次以上走「异化结局」；黑场结局画面按 K 重新开始。
10. 真 HE（隐藏分支）：守门者死后，第三层入口的旧货梯会亮，按 K 回教学关起点；跳过教学步骤，在起点捡发白的骨片，跑到祭坛按 K「归还」。石碗不收献祭数，直接进「真结局 HE」。这条线是可选回头路，不影响普通人类/异化结局。

游戏中按 **Esc** 打开暂停菜单：保存到槽位 1、读取槽位 1、返回游戏；暂停时敌人和玩家都停住。

演示时若来不及打完整套教学，在教学关内按 F2 可直接进第一层。

## 四、系统功能

| 功能 | 说明 |
|---|---|
| 暂停/存档 | Esc 暂停菜单；槽位 1 保存/读档；本地 JSON，Schema v1；主菜单「继续游戏」读最近槽位 |
| 拒绝献祭 | 新手教学祭坛有肢体时按 R，播 `refuse_die` 后进隐藏死亡结局，按 K 回主菜单 |
| 设置 | 音量等（M4） |
| 排行榜 | 登录后查看（M2） |
| 远程存档 | 登录后自动同步（M2） |

## 五、故障与常见问题

| 问题 | 处理 |
|---|---|
| 存档丢失 | 检查 user://saves/ 目录权限 |
| 网络不可用 | 单机照常玩，联网后自动上报 |
| 设置异常 | 删除设置文件重置 |
