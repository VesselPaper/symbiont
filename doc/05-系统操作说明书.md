# 05 系统操作说明书

## 一、快速开始

| 方式 | 步骤 |
|---|---|
| Windows 桌面版 | 运行导出包，或 Godot 编辑器直接运行 |
| Web 版 | 浏览器打开游戏地址（docker 部署的 8080 端口） |
| 本地开发 | scripts/setup.ps1 初始化后编辑器运行 |

## 二、键位表

| 操作 | 键盘 | 手柄（规划） |
|---|---|---|
| 移动 | A / D | 左摇杆 |
| 跳跃 | 空格 | A |
| 攻击 | J | X |
| 下劈 | 下 + 攻击 | — |
| 交互 / 献祭 | K | Y |
| 钩锁 | L（M2 定稿） | RB |
| 暂停 / 菜单 | Esc | Start |
| 演示跳关 | F2（教学关内直接进第一层） | — |

以 project.godot 输入映射为准。

## 三、游戏流程

1. 醒来 → 新手教学（移动 / 跳跃 / 拿剑 / 攻击 / 下劈 / 战斗 / 献祭）；
2. 教学完成 → 地图右侧「第一层」门点亮 → 走进门进入锈钟回廊；
3. 第一层沿路打史莱姆，钟厅、祭坛、断桥、遗物廊、层门各触发一段寄生体低语；
4. 祭坛献祭，获得力量；
5. 层门目前是占位提示（第二层 M3 落地）；
6. 二层抉择阵营（异教徒 / 工程师），三层击败守门 Boss，结算结局。

演示时若来不及打完整套教学，在教学关内按 F2 可直接进第一层。

## 四、系统功能

| 功能 | 说明 |
|---|---|
| 存档 | 3 个槽位，本地 JSON，Schema v1 |
| 设置 | 音量等（M1-06） |
| 排行榜 | 登录后查看（M2） |
| 远程存档 | 登录后自动同步（M2） |

## 五、故障与常见问题

| 问题 | 处理 |
|---|---|
| 存档丢失 | 检查 user://saves/ 目录权限 |
| 网络不可用 | 单机照常玩，联网后自动上报 |
| 设置异常 | 删除设置文件重置 |
