## 1. 玩家操作手册（客户端）

### 1.1 启动与登录
1. 浏览器打开客户端地址（本地开发：`http://localhost:8080`）；
2. 首次使用点击「注册」，填写用户名 / 密码 / 昵称；
3. 已注册用户直接「登录」；也可选择「游客试玩」（本地模式，无云存档 / 排行）。

### 1.2 基本操作（按键）
| 按键 | 动作 |
|---|---|
| A / D 或 ← / → | 左右移动 |
| 空格 / W / ↑ | 跳跃（空中再按 = 二段跳，需能力解锁） |
| Shift / K | 冲刺（需能力解锁） |
| J / X | 攻击 |

### 1.3 游戏目标与流程
1. 在「烬渊」地牢探索，击败敌人、寻找寄生物能力（二段跳 → 冲刺 → 破墙）；
2. 获得共生道具后选择使用方式（食用 / 供奉 / 灌注），影响人性 / 异化值；
3. 挑战跑酷关获取星级；击败 Boss（心核守卫 / 深渊之母）；
4. 依双路线数值走向不同结局。

### 1.4 存档与云存档
- 自动存档点：进入特定区域自动保存；
- 存档界面：3 个槽位，可「上传云端」「下载云端」；
- 冲突提示：云端版本较新时选择「覆盖」或「保留」；
- 死亡后从最近存档点重生。

### 1.5 排行榜
- 主菜单进入「排行榜」；
- 切换维度：通关时间 / 死亡数 / 完成度；总榜 / 关卡分榜；
- 查看个人名次。

### 1.6 设置
- 音量 / 全屏 / 按键说明 / AI 提示开关。

## 2. 管理员操作手册（管理后台）

### 2.1 登录
浏览器打开管理后台（本地开发：`http://localhost:8081`），使用管理员账号登录。

### 2.2 数据看板
查看核心指标：每日活跃折线、关卡通过率柱状、难度分布饼图、游玩时长分布、道具抉择分布、总览数字（玩家数 / 会话数 / 死亡数 / 平均通关时间）。

### 2.3 关卡配置
- 列表查看 / 搜索关卡；
- 新建 / 编辑关卡（JSON 布局数据，含 schema 校验）；
- 启停关卡、查看版本；
- 「AI 生成」：输入主题参数 → 生成关卡 JSON → 校验 → 预览 → 入库发布。

### 2.4 玩家管理
- 查看玩家列表与详情（游玩时长 / 死亡数 / 最后登录）；
- 封禁 / 解封玩家。

### 2.5 公告管理
- 新建 / 编辑 / 启停公告；启用公告会推送到客户端（WebSocket 实时 / REST 拉取兜底）。

### 2.6 管理日志
- 查询管理员操作记录（审计）。
