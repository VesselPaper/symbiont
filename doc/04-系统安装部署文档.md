# 04 系统安装部署文档

## 一、环境要求

| 项 | 要求 |
|---|---|
| Docker | Docker Desktop（Windows）/ docker compose v2 |
| 操作系统 | Windows 11（本项目开发环境） |
| openssl | 生成与校验证书（Git for Windows 自带） |
| Python | 3.12（数据管道与运维脚本） |
| 桌面版运行 | Godot 4.7.2（编辑器直接运行） |
| 浏览器 | 现代浏览器（Web 版） |

## 二、部署架构

```
浏览器
  │  80 → 308 跳转（网关只做跳转，不留明文内容端点）
  ▼
代理 proxy（容器内 8080/8443，宿主机映射 80/443；TLS 终止 / 限流 / 静态托管 / 安全响应头）
  ├── /            跳到 /game/（有游戏包时），否则回退落地页
  ├── /status.html 网关状态页
  └── /api/ ──► upstream 地址池（least_conn + max_fails 摘除 + keepalive）
                     ├── server   :8000（仅内网）
                     ├── server-2 :8000（仅内网，扩容时才有）
                     └── server-3 :8000（仅内网，扩容时才有）
                                │
                                └──► mysql :3306（仅内网）
```

对外只开放 80 和 443。后端与数据库不映射宿主机端口，源站只活在容器网络里。

网关以非 root 用户（uid 101）运行，容器内监听非特权端口 8080/8443，
把"绑定 1024 以下端口"这件事交给宿主机做。

## 三、一键部署

```powershell
scripts/gen_env.ps1        # 生成 deploy/.env（随机数据库密码）
scripts/make_ca.ps1        # 生成本地 CA 与服务端证书
scripts/trust_ca.ps1       # 根证书装进当前用户
scripts/build_images.ps1   # 按 git 短 sha 构建镜像
docker compose -f deploy/docker-compose.yml up -d
scripts/smoke_test.ps1     # 七项检查
```

| 服务 | 地址 | 说明 |
|---|---|---|
| proxy | https://localhost | 入口网关 |
| proxy | https://localhost/status.html | 状态页：看每次请求落到哪台后端 |
| server | 内网 :8000 | 后端，外部不可达 |
| mysql | 内网 :3306 | MySQL 8，首次启动自动执行 schema.sql + seed.sql |

本机若占用 80/443，改 `docker-compose.yml` 的 `ports` 即可。8080 被 Apache、
8000 与 18000 被打印控件占用的机器上也能正常部署，因为容器内不占用这些端口。

## 四、镜像

| 镜像 | 构建文件 | 大小 | 说明 |
|---|---|---|---|
| symbiont-server | `server/Dockerfile` | 329 MB | 多阶段构建；非 root（uid 10001）；内置健康检查；`--no-server-header` |
| symbiont-proxy | `deploy/Dockerfile.proxy` | 94 MB | nginx:alpine；非 root（uid 101）；内置健康检查；配置为 envsubst 模板 |

tag 取 git 短 sha（工作区有未提交改动时带 `-dirty`）。镜像不可变，回滚即切 tag。
依赖安装默认走国内 PyPI 镜像，可用 `--build-arg PIP_INDEX_URL=` 覆盖。

## 五、两种运行形态

| 形态 | 命令 |
|---|---|
| 单副本（默认） | `docker compose -f deploy/docker-compose.yml up -d` |
| 三副本 | 再加 `-f deploy/docker-compose.scale.yml` |

扩容只叠加一个文件：多起两台后端 + 换掉网关的地址池模板，主配置与主模板不动。

## 六、本地开发部署

| 步骤 | 命令 |
|---|---|
| 初始化 | scripts/setup.ps1 |
| 数据管道 | tools/data/build_game_data.py → tools/data/db_export.py |

## 八、故障排查

| 问题 | 处理 |
|---|---|
| 浏览器提示证书不安全 | `scripts/trust_ca.ps1` 装根证书，浏览器重启 |
| 命令行报 `revocation status is unknown` | 加 `--ssl-no-revoke`；内网 CA 无 CRL，详见 `deploy/OPERATIONS.md` |
| 网关起不来，报证书读取失败 | 先跑 `scripts/make_ca.ps1` |
| 80/443 被占用 | 改 `docker-compose.yml` 的 `ports` |
| `/api` 全部 429 | 调 `SYMBIONT_RATE_LIMIT` 后 `up -d` |
| 两份编排互相顶替 | 两个文件都写了 `name:`，不要删 |
| 无网环境 | 单机可玩，网络层自动离线 |
