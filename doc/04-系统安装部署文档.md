# 04 系统安装部署文档

课程交付 4 ｜ 组号：2 组 ｜ 项目：共生之缚 Symbiont

## 一、环境要求

| 项 | 要求 |
|---|---|
| Docker | Docker Desktop（Windows）/ docker compose |
| 桌面版运行 | Godot 4.7（编辑器直接运行） |
| 浏览器 | 现代浏览器（Web 版） |

## 二、一键部署（docker）

```powershell
docker compose -f deploy/docker-compose.yml up -d
```

| 服务 | 地址 | 说明 |
|---|---|---|
| game-web | http://localhost:8080 | 游戏 Web 版（需先 export_web） |
| server | http://localhost:8000/docs | 后端 + OpenAPI |
| mysql | 127.0.0.1:3306 | MySQL 8，自动执行 schema/seed |

## 三、镜像构建

| 镜像 | Dockerfile | 说明 |
|---|---|---|
| server | deploy/Dockerfile.server | FastAPI + uvicorn :8000 |
| game-web | deploy/Dockerfile.game-web | nginx 托管 Web 版游戏，反代 /api |

构建顺序：先导出 Godot Web 版（scripts/export_web.ps1），再构建 game-web 镜像。

## 四、本地开发部署

| 步骤 | 命令 |
|---|---|
| 初始化 | scripts/setup.ps1 |
| 数据管道 | tools/build_game_data.py → tools/db_export.py |
| 后端 | scripts/run_server.ps1 |
| 测试 | scripts/test_all.ps1 |

## 五、验证与故障排查

| 问题 | 处理 |
|---|---|
| 3306 端口占用 | 改 docker-compose 映射端口 |
| Web 版打不开 | 确认已执行 export_web，game-web 镜像重建 |
| 后端起不来 | 看 `docker compose logs server` |
| 无网环境 | 单机可玩，网络层自动离线 |
