## 1. 部署架构

系统由 5 个容器组成，一键编排：

| 服务 | 镜像 | 端口 | 说明 |
|---|---|---|---|
| client | 自建（nginx + Godot WebGL 导出） | 8080 | 游戏客户端网页版 |
| admin-web | 自建（nginx + Vue3 构建产物） | 8081 | 管理后台 |
| backend | 自建（python:3.13-slim + FastAPI） | 8000 | API 服务 |
| mysql | mysql:8.4 | 3306 | 业务数据库 |
| redis | redis:7-alpine | 6379 | 缓存 / 榜单 / 限流 |

> ⚠️ 待补全：镜像构建命令（`docker compose build`）、各服务版本号、镜像导出（`docker save`）说明。

## 2. 环境要求

| 项 | 要求 |
|---|---|
| 操作系统 | Windows 10/11 / Linux / macOS |
| Docker | Docker Engine 26+ / Docker Desktop（WSL2） |
| 浏览器 | Chrome / Edge（WebGL2 支持） |
| 资源 | ≥ 4 核 / 8GB 内存 / 20GB 磁盘 |

## 3. 部署步骤（待构建后补全镜像名与版本）

```bash
# 1. 克隆仓库
git clone https://github.com/VesselPaper/symbiont.git && cd symbiont

# 2. 配置环境变量
cp .env.example .env
#    编辑 .env：MYSQL_ROOT_PASSWORD / JWT_SECRET 等

# 3. 构建并启动
docker compose up -d --build

# 4. 初始化数据库（首次）
docker compose exec -T mysql sh -c 'exec mysql -uroot -p"$MYSQL_ROOT_PASSWORD"' < database/schema.sql
docker compose exec -T mysql sh -c 'exec mysql -uroot -p"$MYSQL_ROOT_PASSWORD"' < database/seed.sql

# 5. 创建管理员账号
docker compose exec backend python -m scripts.create_admin

# 6. 验证
#    客户端：http://localhost:8080
#    管理后台：http://localhost:8081
#    API 健康检查：http://localhost:8000/api/v1/health
```

## 4. 客户端 WebGL 导出说明（待补全）

- 使用 Godot 4.7 打开 `client/project.godot`；
- 导出预设：Web（WebGL2，GL Compatibility 渲染器）；
- 导出产物放置于 `client/build/`，由 `docker/client.Dockerfile` 托管；
- 自动化导出脚本：`scripts/export_webgl.ps1`（规划中）。

## 6. 运维与故障排查（待补全）

- 日志：`docker compose logs -f backend`
- 健康检查：`curl http://localhost:8000/api/v1/health`
- 常见问题：
  - 端口占用 → 修改 `.env` / compose 端口映射；
  - WebGL 无法加载 → 浏览器需开启 WebGL2，检查 COOP/COEP 头；
  - 数据库连不上 → 确认 mysql 容器健康后再启动 backend。
