# 《软件工程》课程设计 —— 项目计划（游戏版）

> 项目名称：《共生之缚》（Symbiont）—— 像素风横版动作探索游戏（类银河恶魔城 + 跑酷）+ 完整后台系统
> 周期：10 周主计划 + 2 周缓冲
> 编制依据：《组号+项目名称+实施周报（模板）》之"整体计划""里程碑计划"
> 说明：以下按"第 X 周"编制，实际日期由开课时间确定后替换；第 1 周起即为 10 周倒计时。

---

## 一、整体计划（10 周主计划 + 2 周缓冲）

> 核心原则：**垂直切片是保险栓** —— 前 3 周只做「1 个房间 + 手感 OK」的可玩切片，验证核心玩法；
> 若跑不通则降级为纯跑酷玩法，保证课程演示下限。

| 编号 | 工作项 | 起止 | 工作任务 | 工作目标 / 交付物 |
|---|---|---|---|---|
| W1 | 选题定稿 + 垂直切片启动 | 第 1 周 | 选题确认、分工、计划制定；搭建 Godot 工程与基础场景（房间/角色/输入） | 选题文档、整体/里程碑计划、可运行的垂直切片骨架 |
| W2 | 垂直切片（手感） | 第 2 周 | 角色控制调校：移动/跳跃/二段跳/冲刺/攻击手感、碰撞、摄像机；1 个巡逻敌人 | **垂直切片 v1：1 房间 + 手感 OK + 敌人**（保险栓达成） |
| W3 | 需求分析 + 探索核心原型 | 第 3 周 | 需求分析（角色/用例/非功能）；客户端探索原型：多房间连通、能力门控 demo、存档点 | 系统功能分析说明书（初稿）；探索闭环原型 |
| W4 | 系统设计（一） | 第 4 周 | 总体架构、接口设计、数据库设计（ER/表结构） | 系统接口设计文档、数据库脚本 v1 |
| W5 | 系统设计（二）+ 后台开发（一） | 第 5 周 | 详细设计（模块/类/时序/关键流程）；后台：账号注册登录、JWT、云存档 API | 系统详细设计；后台基础功能源码 |
| W6 | 后台开发（二） | 第 6 周 | 排行榜、数据统计、公告、管理后台 API；管理端前端（Vue3）骨架 | 后台完整源码、数据库脚本最终版、管理端页面 |
| W7 | 客户端开发（二） | 第 7 周 | 战斗（敌人/Boss）、跑酷挑战关、双路线成长、道具系统、云存档接入 | 完整可玩客户端（本地） |
| W8 | 联调与测试 | 第 8 周 | 客户端 ↔ 后台联调（登录/存档/排行/统计埋点）；单元/接口/集成测试 | 测试报告、缺陷修复、完整可运行系统 |
| W9 | 部署与运维文档 | 第 9 周 | Godot WebGL 导出、Docker Compose 部署、镜像制作、安装部署文档、操作说明书 | 系统安装部署文档（含 Docker 镜像）、系统操作说明书 |
| W10 | 文档收尾与答辩 | 第 10 周 | 源文件说明、7 份文档整合校对、答辩材料、演示视频 | 全部 7 份交付文档 + 源码 |
| W11-12 | 缓冲期 | 第 11-12 周 | 查漏补缺、老师反馈修改、答辩演练 | 最终定稿 |

## 五、风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 老师指定客户端引擎与 Godot 不一致 | 客户端重构 | 引擎以老师为准；后台/管理端/部署不依赖引擎，仅客户端模块调整；垂直切片先行验证玩法 |
| 垂直切片手感不过关 | 演示体验差 | 前 3 周集中调手感；跑不通降级纯跑酷玩法，保证可玩下限 |
| 无专职美术 | 素材拖进度 | 单地牢主题 + ≤8 块 tile 复用 + 程序化粒子，禁止扩展多主题 |
| 过审风险（献祭/寄生/异化题材） | 审核不通过 | 安全化呈现：不血腥不恐怖、发光小精灵系、轻量外观变化 |
| 3 人开发工作量 | 延期 | 范围控制优先（共享内容 80%）、Agent 辅助开发、核心功能先行排序 |
| 云存档并发/冲突 | 数据丢失 | 版本号 + 时间戳冲突策略、校验和防篡改、强制覆盖兜底 |
| 后台 API 高峰卡顿 | 体验差 | Redis 缓存榜单/会话、事件异步落库、限流 |

## 六、量化验收目标（对齐老师题目标准）

| 指标 | 目标 |
|---|---|
| 客户端帧率 | 60 FPS |
| API 响应 | P95 < 200ms（本地/内网） |
| 云存档冲突 | 可恢复（版本+时间戳+覆盖选项） |
| 管理看板图表 | ≥ 3 类核心图表（活跃/通过率/难度分布） |
| AI 关卡生成 | 输出 JSON 100% 通过 schema 校验，生成 < 10s |
| 排行榜 | 万级条目分页查询 < 100ms（Redis 缓存） |
| 交付 | 7 份文档 + Docker 镜像 + WebGL 网页可玩 |
