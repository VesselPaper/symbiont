# 游戏设计文档（GDD）·《共生之缚》

> 项目：《共生之缚》（Symbiont）—— 像素风横版动作探索游戏（类银河恶魔城 + 跑酷 + 双路线成长）
> 版本：v1.0（初稿，作为客户端玩法开发的唯一依据）
> 配套：《美术风格与建模规划.md》《选题-共生之缚（游戏）.md》

---

## 1. 设计定位与参考

### 1.1 一句话定位
一款**类银河恶魔城**游戏：在单一地牢主题「烬渊」中，靠**能力门控**推进探索，用**共生道具的三种用法**驱动**人性↔异化双路线成长**，配合**跑酷挑战关**与**完整后台系统**，走通软件工程全流程。

### 1.2 参考与借鉴（成熟范式）
| 维度 | 参考作品 | 借鉴点 |
|---|---|---|
| 地图/能力门控 | 空洞骑士、密特罗德 | 探索→能力→新区域闭环 |
| 能量/法术/战斗 | 空洞骑士、死亡细胞 | 能量槽 + 消耗型技能、快节奏近战、Boss 阶段战 |
| 平台手感 | 奥日、蔚蓝 | 土狼时间、跳跃缓冲、冲刺的精确平台体验 |
| 死亡惩罚 | 空洞骑士 | 轻惩罚重生（保留进度），死亡计数 |
| 双路线/抉择 | 类 KOTOR/Undertale | 剧情与机制统一的成长抉择 |

### 1.3 差异化（答辩亮点）
1. **双路线成长**：同一个共生道具三种用法（食用/供奉/灌注），抉择**即时可见**（数值+外观+技能+剧情），两路线共享约 80% 地图内容（人力可控）；
2. **能力门控探索闭环**：经典但完整落地；
3. **跑酷挑战关**：独立计时/星级玩法；
4. **后台系统**：账号/云存档/排行榜/统计/管理后台（软件工程考核支撑）；
5. **AI 关卡生成**（可选加分演示）。

## 2. 核心玩法循环

```
探索房间 ──→ 战斗/解谜/跑酷 ──→ 获得寄生物能力 ──→ 解锁新区域
   ↑                                              │
   │                                              ▼
结局/排行榜 ←── 最终抉择 ←── 击败 Boss ←── 成长抉择(人性↔异化) ←── 收集共生道具
```

- **单次会话**：登录 → 读档 → 房间内探索战斗 → 存档点自动保存 → 云同步 → 退出
- **长期目标**：集齐 3 能力 → 击败 2 Boss → 完成共生抉择 → 结局 + 排行榜成绩

## 3. 地图与区域设计

### 3.1 区域总览
| 区域 | 类型 | 关键能力 | 功能 |
|---|---|---|---|
| 上层「烬渊前厅」 | 教学区 | 二段跳 | 新手引导、首个敌人、跑酷关入口 |
| 中层「烬渊中庭」 | 主探索区 | 冲刺 | 主支线、3 个关键道具之一 |
| 深层「烬渊深处」 | 高难区 | 破墙 | 隐藏区、3 个关键道具之二 |
| 心核区 | Boss 区 | — | 心核守卫（Boss 1） |
| 深渊之渊 | Boss 区 | — | 深渊之母（Boss 2）、最终抉择 |
| 跑酷关 ×3 | 挑战关 | 二段跳/冲刺 | 计时 + 星级 |

### 3.2 地图规模与连接
- 总房间数：约 22-24 个主房间 + 3 跑酷关 + 2 Boss 房 + 枢纽
- 连接方式：房间左右门/上下门（见《系统详细设计》门系统）；单向门/门锁做门控
- 探索迷雾：地图外纯黑（免迷雾系统），探索过的区域才渲染 tile

### 3.3 能力门控闭环
```
二段跳（上层获得）→ 可上高层平台 → 中层
冲刺（中层获得）  → 可过宽坑/加速段 → 深层
破墙（深层获得）  → 可破隐藏墙 → 隐藏区/捷径/收集
```

## 4. 胜利 / 失败条件

| 项 | 定义 |
|---|---|
| **胜利（主线）** | 集齐 3 能力 → 击败 2 场 Boss → 最终抉择（人性/异化）→ 触发结局 |
| **胜利（隐藏）** | 人性≈异化（±10 内）+ 3 跑酷关全 3 星 + 收集全部 3 个关键道具 → 「完美共生」结局 |
| **失败（单次死亡）** | HP 归零 → 从最近存档点重生，**保留全部能力/道具/进度**，死亡数 +1（计入统计与排行榜） |
| **失败（跑酷关）** | 时间耗尽 / 掉落深渊 → 本关重试，不影响主进度 |
| **软性失败** | 双路线数值极端失衡 → 错过隐藏结局（非惩罚，可新游戏+补救） |
| **胜利后果** | 结局演出 + 结算（通关时间/死亡数/完成度）自动上报排行榜；解锁「新游戏+」（保留能力重开，可选加分） |

> 死亡轻惩罚设计：不丢进度避免挫败；死亡数作为**反向排行指标**（"谁死得最少"）形成软性竞争，同时是后台统计的关键维度。

## 5. 战斗与技能系统

### 5.1 基础动作
| 动作 | 操作 | 说明 |
|---|---|---|
| 普攻 | J/X | 近战斩击 3 连段，第 3 段击退；面朝方向短判定 |
| 下劈（pogo） | 空中 + 向下按攻击 | 命中敌人/弹/陷阱可弹跳（操作上限） |
| 冲刺 | Shift/K | 位移能力，冷却 1.1s，空中限 1 次（落地重置） |
| 冲刺斩 | 冲刺中攻击 | 1 能量，突进位移 + 破防（对精英/护甲敌人） |

### 5.2 能量系统
- 能量槽：3 格；攻击命中 +0.5 格，击杀 +1 格
- 主动技能消耗能量；少数被动走冷却；能量不自动恢复（回能量道具/击杀补充）

### 5.3 技能表
| 技能 | 归属 | 消耗/类型 | 效果 | 解锁条件 |
|---|---|---|---|---|
| 二段跳 | 共享·能力 | 无 | 地图门控 | 上层剧情 |
| 冲刺 | 共享·能力 | 无 | 地图门控/闪避 | 中层剧情 |
| 破墙 | 共享·能力 | 无 | 地图门控 | 深层剧情 |
| 冲刺斩 | 共享 | 1 能量 | 突进 + 破防 | 击败精英守卫 |
| 圣愈 | 人性线 | 2 能量 | 回复 1 HP | 人性值 ≥60 |
| 回旋剑阵 | 人性线 | 2 能量 | 360° 剑气 | 人性值 ≥80 |
| 格挡反击 | 人性线 | 被动·冷却 1.5s | 受击前格挡→反击 | 人性值 ≥70 |
| 触须穿刺 | 异化线 | 1 能量 | 远程直线贯穿 | 异化值 ≥60 |
| 血噬 | 异化线 | 2 能量 | 命中吸血 | 异化值 ≥80 |
| 加速本能 | 异化线 | 被动 | 击杀后短时提速 | 异化值 ≥70 |

> 两线技能**可兼得**（能量共用），鼓励玩家把一条路线走深 + 留一条路线的余量，为 Boss 双色护盾做准备。

### 5.4 基础数值
| 项 | 数值 |
|---|---|
| HP | 基础 4 格，2 次升级各 +1，上限 6 |
| 受伤 | -1 HP，无敌帧 0.8s |
| 能量 | 3 格上限（可升级 +1） |
| 人性/异化值 | 初始 50/50，范围 0-100 |
| 攻击力 | 基础 1，可升级至 2 |

## 6. 敌人图鉴（详细）

> 通用机制：**前摇提示**（闪白/变色/蓄力音效）→ 攻击 → 硬直；**击退 + 无敌帧**；弹幕可下劈/破坏。

### 6.1 巡逻仆役（Patrol Grub）—— 教学
- 外观：矮胖土灰蠕虫状，单眼暖黄
- 行为：地面巡逻，撞墙/到达边缘回头
- 攻击：接触 1
- HP 1；击打即灭；可下劈弹跳
- 用途：新手第一个敌人，教学移动+攻击+下劈

### 6.2 孢子抛射者（Spitter）—— 远程
- 外观：圆球主体 + 黄绿色孢子囊
- 行为：站桩或慢速移动；周期性发射 1 发**抛物线孢子弹**（发射前囊鼓起）
- 攻击：子弹接触 1；子弹可被攻击破坏，或下劈反弹
- HP 2
- 用途：逼玩家走位/弹反，教"处理投射物"

### 6.3 深渊飞虫（Diver）—— 飞行
- 外观：修长暗青色，薄膜翅
- 行为：空中水平往返；玩家接近后**悬浮 0.6s → 俯冲**（悬浮时闪白预警）
- 攻击：接触 1
- HP 2
- 用途：考验时机与冲刺闪避，配合宽坑增加平台压力

### 6.4 精英守卫（Elite Warden）—— 精英
- 外观：石灰重甲人形，裂纹发红，比主角高 1.5 倍
- 行为 3 段循环：
  1. 近战挥击（前摇举臂 0.7s）
  2. 冲锋（直线突进，需跳跃/冲刺闪避）
  3. 地裂震波（贴地波，需起跳）
- 机制：**正面护甲**——正面攻击无效，需冲刺斩/下劈**破防**后进入硬直再输出；背后可绕后攻击
- HP 5
- 掉落：击败后解锁「冲刺斩」技能

### 6.5 Boss 1 · 心核守卫（Core Warden）
- 外观：大型石像守卫，胸口橙红核心，粗壮手臂
- **阶段 1**（HP 100%→50%）：近战挥击 + 冲锋（前摇=核心蓄光）
- **阶段 2**（HP<50%）：追加地裂震波 + 每 15s 召唤 1-2 只巡逻仆役
- 弱点机制：**核心可破防**（下劈/冲刺斩），破防后硬直 2s 大输出窗口
- HP 12
- 定位：能力/手感/能量的综合测验

### 6.6 Boss 2 · 深渊之母（Mother of the Abyss）
- 外观：巨型触须主体，苍白独眼，紫黑色调
- **阶段 1**（HP 100%→60%）：触须横扫 + 孢子弹幕（弹幕可下劈/破坏）
- **阶段 2**（HP<60%）：追加地面触须柱（**地面闪光预警**，需站位避开）+ **吸摄**（把玩家拉向本体，需反向冲刺挣脱）
- **阶段 3**（HP<30%）：狂暴——攻速 +30%、弹幕密度提升
- 核心机制：**双色护盾**——紫色护盾需人性系技能破除，蓝色护盾需异化系技能破除；促使玩家在两条路线间做出取舍/兼顾
- HP 18
- 定位：全能力/全技能/双路线理解的终极大考

## 7. 角色与成长系统

### 7.1 决策：单主角 + 分能力（不做职业系统）
理由：3 人 + Agent 人力有限；职业系统=多套数值/美术/平衡（工作量翻倍）；能力门控 + 双路线已提供足够深度。职业化列为「新游戏+」可选加分。

### 7.2 主角「无名献祭者」
- 像素小人（米白高亮色块），肩浮发光青白寄生物小精灵
- 成长维度：HP 上限 / 能量上限 / 攻击力 / 移动力（微量，由消耗品与路线加成决定）
- 进度持久化：能力 / 技能 / 人性-异化值 / 地图探索度 / 收集品（存档/云存档）

### 7.3 成长路径
```
道具「共生物质」→ 三选一（食用/供奉/灌注）→ 人性/异化值变化
  → 数值达门槛解锁专属技能 + 外观变化
  → 3 个关键道具推动剧情分叉
  → 最终抉择 → 结局
```

## 8. 共生体实现与特色玩法

**共生体 = 叙事与机制统一的核心**：
1. **能力来源**：所有能力/技能以「共生剧情节点」获得，寄生物化为对应形态（翼/尾/爪/触须）
2. **双轨数值**：共生道具三选一改变人性↔异化
3. **外观反馈**：寄生物光晕随路线渐变（人性=暖金光 / 异化=冷紫荧光）；主角异化时纹路/微光粒子
4. **专属技能**：人性/异化各 2-3 技，数值门槛解锁
5. **剧情反馈**：关键对话与结局随路线分支
6. **共生槽（加分）**：可装备 1 个「共生共鸣」被动（击败特定精英掉落），改变打法风格

**安全化呈现（过审纪律）**：不血腥不恐怖；「献祭」淡化表述；寄生物=发光小精灵系；异化=轻量外观变化。

## 9. 剧情与闯关目的

### 9.1 三幕结构
- **序章**：主角因「仪式」被投入烬渊，濒死时与寄生物共生苏醒（教学关卡）
- **第一幕·上层**：获二段跳；获得关键道具「记忆残片」，首次抉择（食用/供奉/灌注）
- **第二幕·中层**：获冲刺；道具「圣光泪」；击败心核守卫
- **第三幕·深层**：获破墙；道具「深渊髓晶」；发现烬渊真相——它是上古「共生之契」的遗迹，寄生物正是契约的碎片；深渊之母是被遗弃的、未能完成共生的前契约者
- **终章**：击败深渊之母 → 最终抉择 → 结局

### 9.2 结局
| 结局 | 条件 | 内容 |
|---|---|---|
| 人性 | 最终抉择选人性 | 主角剥离共生，以人类身份走出烬渊——失去力量但保有人性 |
| 异化 | 最终抉择选异化 | 完全共生，成为新一任「深渊守望者」 |
| 完美共生（隐藏） | 人性≈异化（±10 内）+ 3 跑酷关全 3 星 + 收集 3 关键道具 | 人形与寄生物达成真正共生，「超越」 |

### 9.3 闯关目的（玩家视角）
- 即时：探索→能力→新区域；战斗成长；收集
- 中期：集齐 3 能力 + 击败 Boss 开启心核
- 长期：完成共生抉择 → 结局 + 排行榜成绩

## 10. 跑酷挑战关设计

| 关卡 | 主题 | 玩法 | 星级阈值（秒） | 解锁 |
|---|---|---|---|---|
| 一环 | 初试身手 | 连续跳跃 + 基础冲刺 | ≤20 / ≤35 / ≤50 | 上层 |
| 二环 | 陷阱密布 | 躲避尖刺/机关 + 二段跳链 | ≤30 / ≤50 / ≤75 | 一环 1 星 |
| 三环 | 深渊疾行 | 全能力综合 + 限时 | ≤40 / ≤65 / ≤95 | 二环 2 星 |

- 机制：计时 + 最佳成绩 + 1-3 星；死亡/掉落/超时即失败重试；成绩上报后端（排行 + 统计）
- 与主线关系：跑酷关独立入口（上层），非主线必需，但**隐藏结局需要 3 关全 3 星**

## 12. 难度曲线与平衡

- 区域强度：上层(教学) → 中层(基础) → 深层(进阶) → Boss 区(挑战)
- 敌人密度：每房间 0-3 只；精英/Boss 为独立节点
- 能量经济：战斗有正收益（命中+0.5/击杀+1），鼓励进攻但控制攒技节奏
- 双路线平衡：两路线 DPS 相近（圣愈=生存向 / 血噬=续航向；剑阵=群伤 / 穿刺=单体贯穿），Boss 双色护盾促使两线各留一技
