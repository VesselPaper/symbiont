# 01 系统功能分析说明书

## 一、系统概述

共生之缚是一款类恶魔城 2D 游戏。背景设定在蒸汽时代的地牢，玩家扮演一名普通骑士，在"献祭获得力量"和"守住人性"之间做选择。

| 项 | 内容 |
|---|---|
| 运行环境 | Windows 桌面、浏览器（Web 版） |
| 技术形态 | Godot 4.7 客户端（纯 GDScript）＋ FastAPI 后端 ＋ MySQL |
| 联网方式 | 单机为主，联网可选（账号/远程存档/排行榜） |

## 二、用户角色

| 角色 | 说明 |
|---|---|
| 玩家（游客） | 不登录直接玩，本地存档 |
| 玩家（账号） | 注册登录后，可远程存档同步 |
| 组员 / 维护者 | 管理数据、部署服务、查看后端探针 |

## 三、功能需求清单

### 3.1 客户端（游戏本体）

| 编号 | 功能 | 说明 |
|---|---|---|
| F-01 | 角色移动与操控 | 移动、跳跃、攻击、下劈（可踩实体反弹） |
| F-02 | 新手教学 | 头顶气泡提示、引导光点、分区环环相扣教学 |
| F-03 | 敌人 | 巡逻史莱姆，可追击、接触伤害、死亡掉落 |
| F-04 | 对话与剧情 | 寄生体低语，打字机逐条，对话时锁定操作 |
| F-05 | 物品与献祭 | 拾取怪物肢体，祭坛献祭计数 |
| F-06 | 摄像机 | 水平跟随 + 垂直死区 |
| F-07 | 任务光点组件 | 通用引导光点，可复用 |
| F-08 | 教学关卡 | 平台、下劈高台、浅坑、祭坛 |
| F-09 | 存档 / 读档 | 本地 JSON 存档，恢复玩家状态 |
| F-10 | 主菜单 + HUD | 开始/继续/设置，血量和献祭计数显示 |
| F-11 | 拒绝献祭结局 | 教学关"宁死不屈"死亡结局 |
| F-12 | 战斗扩展 | 钩锁、二段跳/大跳、武器成长、更多敌人 |
| F-13 | 完整地图 | 三层固定地牢、阵营分支 |
| F-14 | 三结局结算 | 人类 / 异化 / 真 HE |

### 3.2 后端

| 编号 | 功能 | 说明 |
|---|---|---|
| F-15 | 健康探针 | GET /api/v1/health |
| F-16 | 账号 | 注册、登录、token |
| F-17 | 远程存档 | GET/PUT /api/v1/saves/{slot} |
| F-18 | 统计埋点 | POST /api/v1/events |
| F-19 | 排行榜 | GET /api/v1/leaderboard |

### 3.3 数据与部署

| 编号 | 功能 | 说明 |
|---|---|---|
| F-20 | 数据管道 | SQL → SQLite → JSON，运行时加载 |
| F-21 | docker 全栈 | mysql8 + 后端 + nginx 一键拉起 |
| F-22 | Web 导出 | Godot 导出 Web 版，浏览器可玩 |
| F-23 | 数据看板 | 玩家数、事件、结局分布（有余力再做） |

## 四、非功能需求

| 类别 | 要求 |
|---|---|
| 性能 | 目标机 60FPS，2D 占位美术，资源占用低 |
| 可玩性 | 无致命 bug，教学关 5 分钟内通关 |
| 兼容性 | Windows 桌面 + 浏览器，Godot 4.7 统一版本 |
| 网络 | 单机优先，事件离线入队、联网后上报 |
| 数据 | 内容数据由 SQL 导出生成，存档 Schema v1 |
| 安全 | 密码哈希、token 鉴权 |
| 质量 | CI 三 job 全绿、PR review、main 保护 |

## 五、验收标准

1. 三层地牢可玩，双流派、三结局、存档可用、无致命 bug；
2. 后端 FastAPI + MySQL，REST 有 OpenAPI，pytest 全绿，数据真实入库；
3. docker compose 一键拉起，浏览器可玩 Web 版；
4. 课程文档、数据库脚本、周报齐备；
5. CI 绿、main 保护、README 完整。
