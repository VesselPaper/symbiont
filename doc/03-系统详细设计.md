# 03 系统详细设计

## 一、总体架构

| 层 | 内容 |
|---|---|
| 客户端 | Godot 4.7，纯 GDScript，2D |
| 数据管道 | SQL → SQLite → JSON，DataDB 运行时加载 |
| 后端 | FastAPI，分层：路由 → 服务 → 数据访问（SQLAlchemy） |
| 数据层 | MySQL 8（users / saves / events / leaderboard） |
| 部署 | docker-compose：mysql8 + server + nginx |

## 二、客户端设计

### 2.3 全局状态机

BOOT → MAIN_MENU → PLAYING → PAUSED → ENDING / GAME_OVER

状态由 GameManager 管理，切换时经 EventBus 广播。

### 2.4 关键机制

| 机制 | 做法 |
|---|---|
| 玩家移动 | 手感参数常量集中：跳高 3.7×身高、土狼时间、跳缓冲 |
| 攻击判定 | Area2D 判定框，命中 damageable 组目标 |
| 下劈跳高 | 每帧物理空间查询（PhysicsShapeQueryParameters2D），避免漏判 |
| 献祭流程 | 靠近祭坛按 K → 消耗肢体 → 全局计数 +1 |
| 结局结算 | 按献祭次数与旗标判定 |
| 关卡切换 | 教学关献祭完成 → 右侧门点亮 → 走进门 `change_scene_to_file` 到第一层；演示按 F2 直接跳过 |
| 第一层地形 | `floor1.gd` 的 PLATFORMS 数据表驱动，运行时生成 StaticBody2D；改形状只改表，不在编辑器拖节点 |
| 第一层剧情 | 入场延迟 0.6 秒 + 钟厅/祭坛/断桥/遗物廊/层门五个 Area2D 触发器，旗标去重，每段只播一次；空中碰到触发器会等落地再播，走路触发时水平速度立刻归零；对话期间敌人 process_mode 冻结，结束后恢复 |
| 镜头 | 水平 x 加最多 26px 速度前瞻，垂直不再用固定死区：角色站在屏幕偏下（教学关和第一层 56px），上升时镜头额外抬高 26px、下落时下压 12px；水平差超过 480px 或复活起身时垂直差超过 120px 直接吸附 |
| 美术 | 全部代码生成：天光/暗角 shader、远景尖塔、中景尖拱、前景垂藤、轮廓光、雾团、飘尘；不依赖图片素材 |
| 动作动画 | 状态驱动摆件，不动物理：待机呼吸、走步颠步、跳跃/下落姿态、横砍蓄力→挥出→收招、下劈持剑指地、受击缩身泛红、倒地侧倒淡出、复活撑起淡入；动作时长与 0.12s 攻击判定解耦；下落速度 >260 落地才扬尘，命中点炸冷白火花（仅表现，不加判定） |
| 武器表现 | `has_weapon` 决定右臂 SwordPivot 是否可见：空手只画袖口与手，捡剑后亮一下再常驻；挥砍时残影弧线单独显隐；攻击判定框只在逻辑层，原来的蓝色调试矩形已删掉 |
| 怪物表现 | 史莱姆挤压/拉伸 + 随机眨眼 + 死亡压扁淡出（动画结束才掉肢体）+ 死亡绿色孢子；木桩稻草人受击绕脚底晃动 + 闪红，血尽重置不消失 |
| 教学关美术 | `arena_art.gd` 运行时替换灰底：竖直冷光渐变、断柱破拱视差、顶面亮边/横缝/砖缝/青苔、锁链、四盏渐弱吊灯、两根台面断柱、碎石、贴地雾、飘尘、暗角；只改视觉，不动平台碰撞 |

## 三、数据设计

### 3.1 服务器 MySQL

| 表 | 说明 |
|---|---|
| users | 账号，username 唯一 |
| saves | 远程存档，user_id + slot 唯一，save_data JSON |
| events | 埋点，event + payload JSON |
| leaderboard | 排行榜，board + score |

### 3.2 游戏内容库（SQLite）

items / enemies / npc / dialogues / endings / sacrifices 六张表，字段见 schema.sql。

### 3.3 数据管道

改 SQL → build → export → DataDB → 运行时读取。

## 四、服务器设计

| 项 | 方案 |
|---|---|
| 分层 | 路由 → 服务 → ORM |
| 鉴权 | JWT（python-jose），密码 bcrypt 哈希 |
| 埋点 | 批量写入，事件 id 去重 |
| 排行榜 | SQL 排序，board 区分榜单 |

## 五、部署设计

docker-compose 三容器：mysql8 / server / nginx。nginx 反代 /api 到 server，托管 Web 版静态资源。首次启动自动建表。
