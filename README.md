# Symbiont · 共生之缚 🕯️

> 像素风横版动作探索游戏（类银河恶魔城 + 跑酷）

主角因"献祭"被投入深渊地牢，濒死之际被一种深渊寄生物共生，得以存活并获得异于常人的能力。探索中获得的道具，其使用方式将影响主角的成长方向——**偏向"人"，或偏向"非人"**，不同方向解锁不同能力分支，走向不同结局。

本项目为《软件工程》课程设计自主选题（游戏方向）。以"能力门控探索 + 跑酷挑战关卡"为核心玩法，配套账号、云存档、排行榜与数据统计后台，完整走通软件工程全流程。

## ✨ 核心特性

- **能力门控探索**：能力源自寄生物共生（二段跳 / 冲刺 / 破墙），解锁新区域形成探索闭环
- **双路线成长**：共生道具的使用方式影响"人性值 ↔ 异化值"，解锁不同成长分支与结局
- **跑酷挑战关**：时限冲刺、连续跳跃、躲避陷阱，计时评级
- **极简地牢美术**：地图外纯黑虚空，地图内土 + 石墙 tile 复用，低成本高完成度
- **Boss 战与敌人 AI**：巡逻 / 远程 / 飞行 / 精英，阶段式 Boss
- **后台系统**：账号、云存档、排行榜、数据统计、管理后台
- **AI 辅助（可选加分）**：AI 生成关卡布局、卡关渐进提示

## 🛠 技术栈（初步，以老师提供为准）

| 层 | 技术 |
|---|---|
| 客户端 | 倾向 Godot（GDScript，可导出 WebGL）；按老师指定引擎调整 |
| 后台 | Python FastAPI + MySQL + Redis |
| 部署 | Docker Compose（客户端网页版 + 后端 + 数据库） |
| AI（可选） | 大模型 API（DeepSeek 等）生成关卡 / 提示 |

## 🚀 快速开始（开发中，随项目推进完善）

```bash

# 2. 运行客户端（Godot，待技术栈确认后完善）
```

## 🎨 美术规范（地牢极简方案）

> 地图之外大大方方用黑色，地图之内大大方方用土与石墙。

| 元素 | 方案 |
|---|---|
| 地图外 / 未探索区 | 纯黑（#000000），天然迷雾，无需额外迷雾系统 |
| 地图内 | 土 + 石墙 tile 体系（3-5 块基础 tile 复用） |
| 角色与敌人 | 高亮色轮廓（米白 / 暖黄），与黑色背景拉开对比 |
| 交互物（门 / 机关 / 陷阱） | 高亮红 / 橙色标识 |
| 光效点缀 | 程序化粒子（火炬余烬、萤火） |
