## 2. 客户端内部接口

### 2.1 Autoload 单例
| 单例 | 职责 | 关键 API |
|---|---|---|
| EventBus | 事件总线 | 信号（下表）+ `log_event(name, data)` |
| GameManager | 全局状态机 | `start_new_game()/record_sacrifice()/set_flag()/to_dict()/from_dict()` |
| DataDB | 数据访问 | `get_item/get_enemy/get_npc/get_dialogue/get_ending/get_sacrifice/table()` |
| SaveSystem | 存档 | `save(slot)/load(slot)/has_save(slot)`（Schema v1） |
| Settings | 设置 | `load_settings()/save_settings()` |
| Network | 网络 | `configure(base,token)/report_event()/flush_events()/push_save()/pull_save()` |

### 2.2 EventBus 信号表
（player_hurt / enemy_killed / item_picked / sacrifice_done / body_part_modified / save_loaded / save_failed / dialogue_started / dialogue_finished / ending_reached / game_over …… 与 `client/autoload/event_bus.gd` 保持同步）

### 2.3 组件接口（client/components/）
state_machine / health / damageable / hookshot / inventory / dialogue —— M1 起逐个定稿

### 2.4 场景切换协议

## 3. 客户端 ↔ 服务器 REST API（v1）

| 方法 | 路径 | 说明 | 状态 |
|---|---|---|---|
| GET | /api/v1/health | 探针 | M0 ✅ |
| POST | /api/v1/auth/register | 注册 | M2 |
| POST | /api/v1/auth/login | 登录，返回 token | M2 |
| GET | /api/v1/saves/{slot} | 拉远程存档 | M2 |
| PUT | /api/v1/saves/{slot} | 推远程存档 | M2 |
| POST | /api/v1/events | 批量埋点 | M2 |
| GET | /api/v1/leaderboard | 排行榜 | M2 |

鉴权：`Authorization: Bearer <token>`。错误码约定：`{"detail": "..."}`（FastAPI 默认）。
WebSocket：**不做**（单机无实时需求，见 docs/03 §决策记录）。

## 4. 数据管道接口
`database/game_data/*.sql` → `build_game_data.py` → `.db` → `db_export.py` → `client/data/<表>/<id>.json` + `<表>_index.json`。
表清单：items/enemies/npc/dialogues/endings/sacrifices。字段以 `database/game_data/schema.sql` 为准。

## 5. 存档 Schema v1
```json
{
  "version": 1,
  "saved_at": "2026-...",
  "game_progress": { "sacrifice_count": 1, "current_floor": "floor_1", "faction": "", "flags": {} },
  "player": {},
  "inventory": {},
  "levels": {}
}
```
（player/inventory/levels 在 M1/M2 定稿并同步此文档）
