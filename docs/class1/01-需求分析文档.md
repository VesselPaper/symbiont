## 一、项目概述

**一句话定位**：无魔法、蒸汽时代、神明存在的深渊地牢中，一名普通骑士在"献祭获得力量"与"守住人性"之间抉择的类恶魔城 2D 游戏。

**技术形态**：Godot 4.7 客户端（纯 GDScript，2D）＋ FastAPI + MySQL 轻量后端 ＋ docker-compose 全栈部署（方案 B）。

**运行环境**：Windows 桌面 + 浏览器（Web 版导出，暂定）；单机可玩为主，联网可选。

**核心玩法闭环**（已跑通）：醒来 → 新手教学（移动/跳跃/拿剑/攻击/下劈跳高）→ 猎杀怪物 → 拾取肢体 → 祭坛献祭 → 获得力量 → 爬出深渊。

## 二、用户与角色

| 角色 | 说明 | 主要需求 |
|---|---|---|
| 玩家（游客） | 不登录直接玩 | 能玩通教学关，本地存档 |
| 玩家（账号） | 注册登录后 | 远程存档同步、统计上报 |

## 四、非功能需求

1. **性能**：目标机 60FPS；GL Compatibility 渲染；资源占用低（2D 占位美术）。
2. **可玩性**：无致命 bug；教学关 5 分钟内可通关；操作手感（跳高/下劈/反弹）固定可调参数。
3. **兼容性**：Windows 桌面 + 浏览器；Godot 4.7 统一（编辑器/无头测试/CI 同版本）。
4. **无网可玩**：单机优先，网络事件离线入队、联网后上报。
5. **数据一致**：游戏内容数据 JSON 为生成物（改 SQL 再导出），运行时禁止手改；存档 Schema v1。
6. **安全**：密码哈希、token 鉴权（M2）。
7. **代码质量**：CI 三 job 全绿（数据管道 / server pytest / Godot 无头）、PR review、main 保护。

## 五、验收标准

对齐本项目验收标准：
1. 游戏可玩：三层地牢、双流派、三结局、存档可用、无致命 bug；
2. 后端 FastAPI+MySQL，REST 有 OpenAPI、pytest 全绿、数据真实入库；
3. `docker compose up -d` 一键拉起 MySQL+后端+Web 版游戏，浏览器可玩；
4. 课程 7 份文档 + 数据库脚本 + 周报齐备；
5. CI 绿、main 保护、PR review、README 完整。
