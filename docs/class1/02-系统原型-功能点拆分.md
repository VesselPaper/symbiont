- 说明：把整个系统按"模块 → 功能点"拆开，标注实现状态（✅已实现 / ⏳待实现）、对应代码位置与任务卡，作为开发分工和进度跟踪的依据。

## 一、系统整体构成

```
共生之缚 Symbiont
├── 客户端（Godot 4.7，纯 GDScript）     —— 游戏本体，玩家直接操作
├── 数据管道（SQL → SQLite → JSON）     —— 游戏内容数据驱动
├── 后端（FastAPI + MySQL）              —— 账号/远程存档/埋点/排行榜
└── 部署（docker-compose + Web 导出）    —— 全栈一键拉起
```
