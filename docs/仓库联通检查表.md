# 仓库联通检查表

目标：6 名组员都能克隆、都能推送、都能拉取，协作闭环跑通。对应老师本周要求的"仓库联通"。

## 第 0 步（组长做一次）：把组员加进仓库

1. 登录 GitHub（账号：VesselPaper）
2. 打开仓库：https://github.com/VesselPaper/symbiont
3. 点页面上方的 Settings（设置）
4. 左侧菜单选 Collaborators（协作者）
5. 点 Add people，输入组员的 GitHub 用户名，逐个添加
6. 权限选 **Write**（可推送）
7. 组员会收到邀请邮件，点"接受邀请"即可

检查：6 个人的账号都出现在协作者列表里，就完成了。

## 第 0.5 步（组长做一次）：开启 main 分支保护

目标：禁止直接 push main，强制走 PR + CI。仓库 → Settings → Branches → Add branch ruleset（或 Add rule）：

1. Branch name pattern 填 `main`
2. 勾选 **Require a pull request before merging**（至少 1 人 review）
3. 勾选 **Require status checks to pass**，选中 CI 的检查项（data-pipeline / server / client）
4. 勾选 **Do not allow bypassing the above settings**（管理员也受约束）
5. 保存

开启后组员直接 `git push` 到 main 会被拒绝，必须按下面的 PR 流程走。

## 每人要做的事项（做完打勾）

| 序号 | 事项 | 命令 / 操作 | 完成 |
|---|---|---|---|
| 1 | 安装 Git | 到 https://git-scm.com 下载安装，一路下一步 | ☐ |
| 2 | 配置身份 | `git config --global user.name "你的名字"`，再运行 `git config --global user.email "你的邮箱"` | ☐ |
| 3 | 克隆仓库 | `git clone https://github.com/VesselPaper/symbiont.git` | ☐ |
| 4 | 初始化环境 | 进入 symbiont 文件夹，运行 `scripts\setup.ps1`（自动装 Godot 和依赖） | ☐ |
| 5 | 能打开游戏 | 打开 Godot，导入 `client\project.godot`，按 F5 看到 M0 标题页 | ☐ |
| 6 | 提交闭环 1 | 把下面"成员签名"里自己那一行加上名字（这就是一次"改文件"） | ☐ |
| 7 | 提交闭环 2 | `git checkout -b feature/签到-你的名字` → `git add .` → `git commit -m "docs: 签到"` → `git push -u origin feature/签到-你的名字` | ☐ |
| 8 | 提交闭环 3 | 到 GitHub 开 PR → CI 绿 → 合并；过一会儿 `git checkout main; git pull`，能看到别人新提交的内容 | ☐ |

说明：第 6-8 步就是完整的"分支 → PR → 合并"闭环（见 README"四、团队协作"）。如果 push 被拒、CI 报红或出现冲突符号，都是正常的，按 README 处理，或者截图发群里组长帮你合并。
