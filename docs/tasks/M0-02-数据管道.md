# M0-02 数据管道（SQLite → JSON → DataDB）

- 编号：M0-02 ｜ 指派：agent
- 输入：`database/game_data/schema.sql`、`seed.sql`；`tools/` 说明；`docs/02`（数据接口约定）
- 改动范围：`tools/`、`client/autoload/data_db.gd`、`client/data/`
- 实现要求：
  1. `tools/build_game_data.py`：执行 schema+seed 生成 `database/game_data/game_data.db`
  2. `tools/db_export.py`：按表导出 `client/data/<表>/<id>.json` + `*_index.json`（表列表与 DataDB.TABLES 一致）
  3. `client/autoload/data_db.gd`：启动加载全部表，提供 `get_item/get_enemy/get_dialogue/get_ending/get_sacrifice/table()`
- 验收标准：
  - [ ] `python tools/build_game_data.py && python tools/db_export.py` 成功，`client/data` 出现 6 个表目录
  - [ ] `pytest tools/tests -q` 通过（含正式数据自检：4 个结局存在）
  - [ ] Godot headless 冒烟通过（DataDB 表结构可用）
- 禁止：手改 `client/data/`；给 JSON 加表外字段而不同步 schema
- 产出：管道代码 + 测试 + 完成报告
