## 一、要做什么（大白话）

把现在教学关里"地上的小方块标记"升级成**通用任务光点组件**（quest_marker）：
1. 光点**漂浮在空中**（上下悬浮动画）
2. **常驻粒子特效**（光点周围一直有粒子飘散）
3. 玩家接触后：**有效果**（闪光 + 粒子爆发）然后消失；**也可以配置成"逃跑飘向远方"**（接触后飞走）
4. 触发时广播事件（`EventBus.marker_triggered(marker_id)`），**后续剧情/任务都能监听**（不只教学用）
5. 软隔离保留：光点默认不激活，触碰无效；教程到对应环才 `activate()`，激活后接触才触发

## 二、组件设计

### 1. 新组件 `client/scenes/items/quest_marker.tscn` + `client/scripts/items/quest_marker.gd`
- 根节点 Node2D，结构：
  - **本体视觉**：菱形 Polygon2D（亮青色 `Color(0.35, 0.9, 1)`）+ 外围半透明光晕（同色 alpha≈0.25，比本体大一圈）
  - **悬浮动画**：`_process` 里 `position.y` 正弦浮动（`float_amplitude`、`float_speed` 可调，默认 6.0 / 2.5）
  - **常驻粒子**：CPUParticles2D（**必须用 CPUParticles2D，GL Compatibility 渲染器下 GPU 粒子兼容性差**），emitting=true，青白色小点向四周缓缓飘散（数量少、寿命短、小尺寸）
  - **爆发粒子**：第二个 CPUParticles2D，默认 emitting=false；触发时一次性 burst（数量多、扩散快、寿命更短），播完自动停
  - **碰撞**：Area2D（collision_layer=0, collision_mask=2 只探测玩家，shape 约 40x40 覆盖本体）
- export：
  - `marker_id: String`（标识，triggered 广播携带，教程用它匹配）
  - `fly_away_on_touch: bool = false`（true = 接触后飘向远方）
  - `fly_away_velocity: Vector2 = Vector2(300, -120)`（飘走速度，向右上方飘）
  - `float_amplitude: float = 6.0`、`float_speed: float = 2.5`
- 行为：
  - `active: bool = false`（软隔离，默认关）；`activate()` 开触碰（Area2D monitoring 开）
  - `body_entered`（玩家）且 active → 触发
  - 触发流程（防重复，`_triggered` 标记）：
    1. 闪光：本体 scale 弹跳一下（Tween 或手动，0.2s 内 1→1.4→1）
    2. 爆发粒子 burst（emitting=true 一次性）
    3. fly_away_on_touch：本体按 `fly_away_velocity` 匀速飞走（_process 更新位置），离开场景/视口后 `queue_free()`；否则本体淡出（modulate a 渐隐）后 `queue_free()`
    4. `EventBus.marker_triggered.emit(marker_id)`
  - 触发后 Area2D monitoring 关闭（不再触发）
- 参考现有代码风格（limb_pickup.gd 的浮动、slime.gd 的常量组织）；反向测试规范（触碰判定只认玩家）

## 三、验收标准

- [ ] 无头启动无报错，smoke_test 通过
- [ ] 临时无头测试（跑完删除，含 .uid）：
  - quest_marker 实例化无报错；未 activate 时模拟玩家进入（或直接调触发方法）不触发、不 emit；activate 后触发 → EventBus.marker_triggered 收到对应 marker_id、本体开始消失/飞走、防重复（二次触发无效）
  - tutorial 事件链：WEAPON→(铁剑)→MOVE→(move_mark 触发)→JUMP→(jump_mark 触发)→ATTACK→POGO→COMBAT→PICKUP→SACRIFICE→DONE 逐级到位
- [ ] F5：行走光点悬浮空中带粒子，走到下方接触 → 闪光+粒子爆发消失 → 进跳跃环；跳跃光点在台上，跳上去接触 → 效果同上。至少一个光点配成 fly_away 看逃跑效果（可先都 fly_away_on_touch=false，验收时看逃跑效果再开）

## 四、禁止

- 不改平台布局/玩家手感/台词（本轮只做光点）
- 不用 GPUParticles2D（Compatibility 兼容问题，用 CPUParticles2D）
- 不做 HUD/任务系统 UI（M1-06 范畴）；组件只负责"光点 + 触发广播"，后续任务逻辑由监听方写
