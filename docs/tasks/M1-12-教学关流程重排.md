## 一、要做什么（大白话）

教学关**流程顺序和关卡布局整体重排**，新顺序（用户定稿）：

**开始游戏 → 教左右移动（走到白色光点）→ 教跳跃（跳上第一个矩形平台）→ 跳上平台后看见尸体、获得剑 → 打木桩（攻击）→ 遇到更高的地方：普通跳跳不上去，需"下劈木桩反弹"跳上去 → 打一个怪 → 捡肢体 → 走台阶 → 到祭坛献祭**

关卡只保留：
1. **第一个矩形平台**（跳跃教学，上面放尸体+剑、攻击木桩）
2. **第二个更高平台**（下劈教学：普通跳跳不上去，下劈木桩反弹上去）
3. **台阶**（通往祭坛，祭坛在最高处）

## 二、核心设计

### 1. 光点改成"单个引导光点"（用户定稿：取消粒子，隐隐约约的白色光点，触碰后飞到下一个目标地点）
- **quest_marker.tscn**：去掉大量粒子效果（删除 AmbientParticles / BurstParticles 两个 CPUParticles2D，或仅保留极淡小点——用户要求"取消大量粒子效果"，直接删干净）；Body 改**纯白半透明** `Color(1,1,1,0.6)`（隐隐约约）、尺寸调小（菱形 8×8 左右）；Halo 白色更淡 `Color(1,1,1,0.2)`；保留小幅悬浮（float_amplitude 可保持 6 或调小）
- **quest_marker.gd 行为改造**：
  - 新增 `move_to(target_pos: Vector2)`：光点平滑飞向下一个目标点（Tween，约 0.5s），到达后在目标点上方悬浮等待
  - 触碰（active 时 body_entered）→ emit `EventBus.marker_triggered(marker_id)` → **不再自动消失/飞远**（由 tutorial 收到信号后调用 move_to 指定下一个目标）
  - 防重复改造：每次 `move_to` 后重置触发标记（玩家走到新位置可再次触碰触发），保证"触碰→飞到下一目标→再触碰"循环
  - 软隔离 active/activate() 保留（tutorial 到 MOVE 激活）
- **test_arena.tscn**：只放**一个**引导光点（如 `guide_mark`，marker_id="guide_mark"），初始位置在移动目标点 (475, 640)；删除 move_mark/jump_mark 两个实例；Tutorial 的 `move_marker_path` 指向它
- **tutorial.gd**：
  - 新增 `MARKER_TARGETS: Array[Vector2]`（每步光点引导位置，按 Step 顺序）：
    - MOVE (475,640) / JUMP (660,540) / WEAPON (730,540) / ATTACK (830,540) / POGO (1100,400) / COMBAT (1450,340) / PICKUP (1550,340) / SACRIFICE (1550,340)
  - `_advance()` 进入某步时调用 `_move_marker_to(MARKER_TARGETS[step])`（光点飞向下一个引导点）
  - MOVE/JUMP 步收到 `marker_triggered` → 推进（只有一个光点，不再用 marker_id 区分，但保留字段兼容）；其余步按动作推进

### 3. tutorial.gd 状态机重排
新顺序：`WAIT_FOR_DIALOGUE → MOVE → JUMP → WEAPON → ATTACK → POGO → COMBAT → PICKUP → SACRIFICE → DONE`
- MOVE：move_mark 触发（走到地面光点）→ 进 JUMP
- JUMP：jump_mark 触发（跳上第一平台）→ 进 WEAPON
- WEAPON：`item_picked("iron_sword")` → 短显示"获得铁剑" → 进 ATTACK
- ATTACK：假人甲受击一次 → 进 POGO（activate 假人乙）
- POGO：假人乙受击一次（下劈命中）→ 进 COMBAT（spawn 史莱姆）
- COMBAT：击杀 → PICKUP；PICKUP：拾肢体 → SACRIFICE；SACRIFICE：献祭 → DONE
- 气泡文案（BUBBLE_TEXTS 按新顺序）：
  - MOVE "走到前面的光点（A/D）"
  - JUMP "跳上平台（空格）"
  - WEAPON "拿上那把剑"
  - ATTACK "用 J 攻击木桩"
  - POGO "跳过去，下落时按 J 下劈反弹"
  - COMBAT "击杀它（J）"
  - PICKUP "捡起肢体，献给我"
  - SACRIFICE "带到祭坛，按 K 献祭"
- 状态机顺序变化注意：activate 光点/假人的时机跟着新顺序走（进 MOVE activate move_mark、进 JUMP activate jump_mark、进 POGO activate 假人乙……）；`_advance()` 里的 spawn 逻辑仍在进 COMBAT 时触发
