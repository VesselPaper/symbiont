# M1-10 新手教程改版：头顶提示 + 环环相扣分区教学 + 武器剧情

- 编号：M1-10 ｜ 指派：待认领（agent）
- 依赖：M1-01（玩家/假人）、M1-02（史莱姆掉肢体）、M1-04（祭坛献祭）、M1-08（旧教程，将被替换）
- 状态：已定稿（组长已和用户确认两个决策：软隔离 + 剧情拾取武器[按 J 静默无效]）

## 一、要做什么（大白话）

把现在的新手教程整体改版，解决三个问题：
1. **提示不显眼**：旧提示条在屏幕上方 → 改为**主角头顶跟随**的气泡提示（字大、有背景板、永远在玩家头顶）
2. **跳转太快**：旧教程"按一下键就跳下一环" → 改为**目标达成式分区教学**：一环一个区域，走到哪/跳到哪/打到哪才推进，一环扣一环
3. **没有武器剧情**：开场醒来 → 先**通过剧情获得武器**，再开始攻击教学；没武器时按 J 无效（静默，不弹提示）

两个已确认决策：
- **软隔离**：地图开放，但"后一环的目标在轮到它之前不生效"——假人默认不激活（打了没反应）、史莱姆只在战斗环生成、祭坛要肢体才能献祭。不设门/墙。
- **武器**：剧情拾取 + 没武器不能攻击（按 J 静默无效，不提示"没有武器"）。

## 二、核心设计（按此实现）

### 1. 武器剧情（新前置环 WEAPON）
- 场景布置：出生点附近地面（x≈200，贴地 y≈680）放一把插地的剑 = **武器拾取物**（视觉比肢体醒目：亮蓝白色 + 微微发光/闪烁），旁边放一具**遇难者尸体**（Polygon2D 占位：灰色横躺人形色块，长条形即可）
- 对话引导（改 `database/game_data/seed.sql` 台词，重跑数据管道导出）：intro_parasite_1 加一句交代剑的来历 —— 寄生体说"看，上一个被丢下来的人。他的剑，拿上它。"（可把"去猎杀"那句往后挪，保持"醒来→武器→猎杀→献祭"的叙事顺序，2~4 句均可，口吻延续上版低语风）
- 玩家碰到武器拾取物 → `EventBus.item_picked.emit("iron_sword", 1)` → 头顶提示"获得铁剑"短暂显示 → 进入行走环
- **player.gd 加 `has_weapon: bool = false`**：_ready 里监听 `EventBus.item_picked`，`item_id=="iron_sword"` 时置 true；`_try_start_attack()` 函数开头加 `if not has_weapon: return`（**静默**返回，不弹任何提示）。**不得改动任何手感常量/其他逻辑**

### 4. 教学假人（软隔离核心）
- 改 `client/scripts/entities/dummy_target.gd`：加 `active: bool = false` + `activate()` 方法；`take_damage()` 开头加 `if not active: return`（未激活时打了没反应，即"提前做后一环无事可做"）
- tutorial 到 ATTACK 环时 `activate()` 假人甲；到 POGO 环时 `activate()` 假人乙
- 假人受击检测：tutorial 每帧读当前环假人的 `hp`（`get("hp")`），比初始 MAX_HP 小即推进（打一下就行，不用打死）；推进后 _step 变化自然防抖

### 5. tutorial.gd 状态机改造
新状态：`WAIT_FOR_DIALOGUE → WEAPON → MOVE → JUMP → ATTACK → POGO → COMBAT → PICKUP → SACRIFICE → DONE`
- WEAPON：监听 `item_picked("iron_sword")` → 显示"获得铁剑"短暂 → 推进 MOVE
- MOVE/JUMP：每帧用**坐标矩形判断**玩家是否进入当前标记区（Rect2 常量定义在 tutorial.gd 顶部，注释写明与 test_arena 视觉对齐），`_step` 匹配才推进（提前踩进去不推进，轮到时已在区域内立即推进）
- ATTACK/POGO：每帧检查对应假人 hp（见上）
- COMBAT：`enemy_killed` → PICKUP；PICKUP：`item_picked("monster_limb")` → SACRIFICE；SACRIFICE：`sacrifice_done` → DONE
- 气泡文字常量（UI 提示，允许硬编码）：见上表 + DONE 用"教程完成"（短暂显示后隐藏）
- 事件驱动为主（武器/击杀/拾取/献祭走事件），区域/假人检测走每帧检查（同现有 pogo 边沿检测风格）
