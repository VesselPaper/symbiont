# Agent 任务卡模板（TASK CARD）

每个 agent 任务一张卡。**开工前必读**：任务依赖的设计文档章节；**提交前自检**：验收标准逐条打勾。

## 任务名 / 编号

- 编号：`M<x>-<nn>`（如 M0-01）
- 标题：一句话
- 指派：`agent:<名称>` 或 `人:<姓名>`

## 输入（前置依赖）

- 设计文档章节：`docs/design/GDD.md §x`、`docs/02-系统接口设计文档.md §x`、`docs/03-系统详细设计.md §x`
- 数据/接口：涉及的表、JSON、信号、REST 端点
- 依赖任务：前置任务卡编号

## 改动文件范围

明确列出允许修改/新增的路径（例如 `client/scripts/player/`、`client/scenes/player/`）。**范围外文件一律不许动。**

## 实现要求（逐条）

1. ...
2. ...

## 验收标准（可运行检查点，全过才算完成）

- [ ] ......
- [ ] `godot --headless ...` 通过 / `pytest ...` 通过
- [ ] CI 绿

## 禁止事项（红线）

- 不重构范围外代码、不改已定接口/信号签名、不发明新功能
- 不调数值（数值一律进 `database/game_data` 或 JSON）
- 不引入新依赖（如需新增，先写决策日志 D-xxx）

## 产出

- 代码 + 测试 + 一句完成报告（做了什么、验收如何、遗留问题）
