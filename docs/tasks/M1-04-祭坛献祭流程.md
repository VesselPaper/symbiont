## 一、要做什么（大白话）

让玩家能把"怪物肢体"拿到祭坛献祭，走完 **击杀史莱姆 → 捡肢体 → 到祭坛按 K 献祭 → 计数+1** 这条新手主线的完整闭环。第一次献祭是主线必经。

当前进度：史莱姆死亡已会掉肢体，玩家碰到已会拾取并广播 `item_picked("monster_limb",1)`，但**捡了没计数、世界上没有祭坛、教程没有引导献祭**。本任务补齐这三块。

## 二、改动范围（定稿，别动别的）

1. **`client/autoload/game_manager.gd`**：加怪物肢体持有数
   - 加变量 `monster_limb_count: int = 0`
   - 加方法 `add_monster_limb(n: int)`（自增）和 `try_consume_monster_limb() -> bool`（有肢体才 -1 并返回 true，没有返回 false）
   - `_ready()` 里监听 `EventBus.item_picked`：`item_id == "monster_limb"` 时 `add_monster_limb(count)`
   - `to_dict()` / `from_dict()` 带上 `monster_limb_count`（M1-05 存档要用）
   - `start_new_game()` 里重置为 0

2. **新建 `client/scenes/items/altar.tscn` + `client/scripts/items/altar.gd`**（祭坛，占位美术即可）
   - 根节点 Area2D，`collision_layer=0`、`collision_mask=2`（只探测玩家），挂 `altar.gd`
   - 视觉占位：Polygon2D 台座（暗紫色，宽约 80 高约 30，底边贴地）+ 顶部一个小方块当"石台"
   - 世界空间 Label（祭坛上方）：中文必须 Noto Sans CJK 字体（`res://assets/fonts/NotoSansCJKsc-Regular.otf`，_ready 里 load 并 `add_theme_font_override`，同 dialogue_box）
   - 行为：
     - `body_entered` / `body_exited` 记录玩家是否在范围内（mask=2，只认玩家）
     - 玩家在范围内：Label 显示"按 K 献祭"；离开：隐藏
     - 玩家在范围内 且 玩家未锁输入时，`interact`(K) 按下 → 献祭：
       - `GameManager.try_consume_monster_limb()` 成功 → `GameManager.record_sacrifice("generic")` → Label 短暂显示"献祭成功"
       - 没有肢体 → Label 短暂显示"没有可献祭的肢体"
     - 玩家锁输入的判断：duck typing 读 `player.get("_input_locked")`（对话期间不响应，防与对话抢 K）
     - 输入触发做反向测试（规范第 6 条）：只有 K 的按下沿触发，抬起 / echo / 其它键一律忽略

3. **`client/components/tutorial.gd`**：教程加 2 步
   - 状态机从 `MOVE→JUMP→ATTACK→POGO→COMBAT→DONE` 改成 `…→COMBAT→PICKUP→SACRIFICE→DONE`
   - `STEP_HINTS` 加两项：捡肢体"捡起地上的怪物肢体"、献祭"到祭坛按 K 献上肢体"
   - `_on_enemy_killed`：COMBAT 击杀后推进到 PICKUP（提示捡肢体）
   - 监听 `EventBus.item_picked`：`item_id=="monster_limb"` 且当前 PICKUP 步 → 推进到 SACRIFICE
   - 监听 `EventBus.sacrifice_done`：当前 SACRIFICE 步 → 推进到 DONE（"教程完成"短提示，照抄现有逻辑）
   - 事件驱动，不要每帧轮询；同现有代码风格

4. **`client/scenes/world/test_arena.tscn`**：放祭坛
   - 实例化 altar，位置 `Vector2(1300, 690)`（木桩 DummyTarget 在 1094，祭坛放它右侧；底边贴地面 y=690）

5. **`client/tests/smoke_test.gd`**：加肢体计数断言（`add_monster_limb` → count 为 1 → `try_consume_monster_limb()` 返回 true 且 count 为 0；没肢体时返回 false）
