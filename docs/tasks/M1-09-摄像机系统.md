# M1-09 摄像机系统（拉近 + 跟随 + 视野限幅）

- 编号：M1-09 ｜ 指派：技术主力（自行实现）
- 依赖：M1-01（场景结构）
- 输入：`client/scenes/world/test_arena.tscn`、`client/scripts/world/test_arena.gd`
- 改动范围：`client/scenes/world/test_arena.tscn`（地图加宽、Camera2D 配置）、`client/scripts/world/test_arena.gd`（相机挂载逻辑，必要时）、`docs/`（摄像机配置规范）
- 问题背景：测试竞技场 = 视口大小（1280x720）+ zoom=1 → 画面直接看到全部地图，且角色（28px 高）显得很小。需要"看不到全图 + 角色放大 + 镜头跟随"。
- 实现要求：
  1. 地图加宽到约 2~3 屏（2560x720）：地面/左右墙/背景同步加宽，平台与敌人位置可保留
  2. Camera2D：**zoom 拉近**（如 Vector2(2.5, 2.5)，可调），跟随玩家（reparent + smoothing 已有），limit 覆盖整个地图（left=0, top=-120, right=地图宽, bottom=720）
  3. 配置标准化：zoom/limit 写成可调参数，并在 docs/03 或本任务卡记录"楼层场景摄像机规范"（后续 M2/M3 复用）
  4. 不影响：玩家移动/攻击/下砍、对话、教程、史莱姆生成
- 验收标准：
  - [ ] 无头启动无报错，smoke_test 退出码 0
  - [ ] 临时测试：Camera2D.zoom==2.5、limit_right==2560、相机已挂到玩家
  - [ ] F5：画面只显示角色周围一小片（看不到全图），角色明显变大，镜头平滑跟随移动不掉队
- 禁止：改 player.gd 核心逻辑；改 docs/database/tools/server
- 产出：代码 + 验证报告
