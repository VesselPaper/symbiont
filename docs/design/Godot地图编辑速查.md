# Godot 编辑器地图编辑速查（组员用）

> 适用：在 Godot 编辑器里改教学关/地图（如 `scenes/world/test_arena.tscn`）的物件形状、大小、层级。
> 打开场景：编辑器文件系统面板双击 `scenes/world/test_arena.tscn`。

## 一、选物体 & 三个基本工具

| 工具 | 快捷键 | 干什么 | 怎么用 |
|---|---|---|---|
| 选择/移动 | `W`（或直接点物体） | 选中 + 拖动位置 | 点选物体 → 按住拖动；箭头键微调 |
| 旋转 | `E` | 转角度 | 选中 → 拖蓝色圆弧手柄；Inspector 的 Rotation 可精确输入（弧度，180°=3.14159） |
| 缩放 | `R` | 整体放大缩小 | 选中 → 拖角点手柄（Shift 等比）；Inspector 的 Scale 可精确输入 |

- 场景树（右上）点节点名 = 选中；在 2D 视口点图形 = 选中
- 按住 `Ctrl` 点多个 = 多选（可一起移动/对齐）

## 二、拉伸（改大小）

两种方式，别混：

**A. 整体缩放（R 工具 / Scale 属性）**——简单但会"拉伸变形"整个节点（包括碰撞），一般用于整体放大缩小，慎用于平台（会把碰撞也变）。

**B. 改尺寸（推荐用于平台/矩形物体）**：
- 选中 `CollisionShape2D` 子节点 → Inspector → `Shape`（RectangleShape2D）→ **Size** 填宽高（如 Vector2(300, 90)）——这是碰撞体大小
- 再选中同级的 `Visual`（Polygon2D）→ 多边形编辑（见第三节）改视觉大小，**让视觉和碰撞对齐**
- 注意：平台是"碰撞 + 视觉"两个节点，改尺寸要两个都改（或整体 Scale 两者同步，但 Scale 后 Inspector 数值会变小数，不好维护）

## 三、改形状（多边形）

我们的剑、尸体、平台视觉、光点都是 **Polygon2D**（多边形）：

1. 场景树选中 Polygon2D 节点（如剑的 `Visuals/Blade`）
2. 2D 视口**顶部工具栏**会出现"多边形编辑"按钮（折线/五边形图标），点击进入编辑
3. 视口里出现**顶点小方块**：
   - **拖动顶点** = 改形状
   - **边上右键** = 添加顶点
   - **顶点上右键** = 删除顶点
4. 改完再点一下工具按钮退出
5. 也可以直接改 Inspector 的 `Polygon` 数值（每个顶点坐标）

碰撞形状同理：`CollisionShape2D` 的 shape 若是 `RectangleShape2D` 改 Size；若是 `PolygonShape2D` 用同一个多边形编辑工具。

## 四、调整层级（谁盖谁）

规则（详见 `docs/design/渲染层级.md`）：
1. **CanvasLayer 的节点永远最顶**（UI：对话框）
2. 世界层比 **Z Index**（Inspector → Ordering → Z Index）：数字大盖数字小，负数在最下
3. Z Index 相同时，看**场景树顺序**：树里**靠后的盖靠前的**（后画的在上面）
4. 子节点默认 `Z As Relative=true`：实际层级 = 父节点 + 子节点

操作：
- 改单个节点层级：选中 → Inspector → Ordering → **Z Index** 改数字
- 改渲染顺序（同层）：**在场景树里上下拖动节点**（拖到后面的会盖住前面的）
- 我们项目的约定：
  - 背景 Backdrop：z=-2（最底）
  - 剑：z=-1（插进地形/尸体，被它们盖住露出部分）
  - 地面/平台/尸体/光点/玩家/敌人：z=0（靠树顺序）
  - UI：CanvasLayer（最顶）

## 五、常用技巧

| 想干什么 | 操作 |
|---|---|
| 复制一个物体 | 选中 → `Ctrl+D`（Duplicate） |
| 吸附网格/对齐 | 顶部"磁铁"图标开 Snap；View 菜单可调网格 |
| 对齐多个物体 | 多选 → 顶部对齐按钮（左/中/右/顶/底） |
| 快速看某个物体 | 选中 → 按 `F`（聚焦） |
| 看坐标 | 2D 视口底部状态栏显示鼠标/选中物体的坐标 |
| 微调位置 | 选中 → 方向键（Shift+方向键 = 10px 大步） |
| 撤销 | `Ctrl+Z` |

## 六、容易踩的坑（本项目教训）

1. **改平台只改了视觉没改碰撞**（或反过来）→ 玩家穿模/卡住。改大小务必视觉+碰撞一起。
2. **新物件忘了想层级** → 被背景盖住看不见（剑 z=-1 时背景必须更低，z=-2）。
3. **用 Scale 拉伸平台** → Inspector 数值变小数，之后难调；平台改尺寸用 Shape Size。
4. **编辑器保存后属性被写进场景实例**（如 float_amplitude）→ 改脚本默认值时注意实例覆盖。
5. **保存时别把 project.godot 升到 4.7**（弹窗一律点取消；场景文件 tscn 用 4.7 保存没问题）。

## 七、改完怎么验证

- 编辑器里 `F6` = 运行当前场景；`F5` = 运行主场景（教学关）
- 无头测试（不弹窗）：`Godot_v4.5.1-stable_win64.exe --headless --path client --script res://tests/smoke_test.gd`
