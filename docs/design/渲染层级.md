# 渲染层级说明（当前各部分层级一览）

> 目的：让组员看清现在的层级关系，**以后加任何新形象/物件都要先查本表、登记本表**，
> 避免"被挡住 / 盖住别人"的层级 bug（教训：剑刃被光晕盖住、剑被背景盖住）。

## 一、Godot 渲染规则（先懂这三条）

1. **CanvasLayer 永远在 2D 世界之上**：UI（对话框等）挂 CanvasLayer，一定盖住所有场景内容。
2. **世界层比 z_index，再比场景树顺序**：
   - 先看 **z_index**：数字大的盖数字小的（负数在最下面）。
   - z_index **相同**时，看场景树里谁排**后面**——后面的盖前面的（先画的在底下）。
3. 子节点默认 `z_as_relative=true`：实际 z = 父节点 z + 子节点 z。

## 二、当前层级表（教学关 test_arena）

### UI 层（CanvasLayer，永远最顶）

| 元素     | 节点                                               | 层                                                         |
| -------- | -------------------------------------------------- | ---------------------------------------------------------- |
| 对话框   | `DialogueBox`（scenes/ui/dialogue_box.tscn）       | CanvasLayer（最顶）                                        |
| 教程气泡 | `TutorialBubble`（scenes/ui/tutorial_bubble.tscn） | **注意：世界空间 Node2D**（不是 UI），跟随玩家头顶，见下表 |

### 世界层（从下到上）

| 顺序 | 元素      | 节点                                                                             | z_index            | 说明                                                                          |
| ---- | --------- | -------------------------------------------------------------------------------- | ------------------ | ----------------------------------------------------------------------------- |
| 1    | 背景      | `Backdrop`（Polygon2D）                                                          | 0（**计划改 -2**） | 全屏深色底，最底                                                              |
| 2    | 地形      | `Ground` / `WallLeft` / `WallRight` / 各平台（StaticBody2D 的 Visual Polygon2D） | 0                  | 地面、墙壁、高台                                                              |
| 3    | 场景物件  | `Corpse`（尸体 Body/Head）                                                       | 0                  | 遇难者占位                                                                    |
| 4    | 拾取物    | `WeaponPickup`（剑）                                                             | -1                 | 比地形/尸体低：插入地面和尸体的部分被它们盖住（"插进去"效果）；露出部分仍可见 |
| 5    | 任务光点  | `move_mark` / `jump_mark`（quest_marker）                                        | 0                  | 悬浮引导光点（M1-12 将改成单个白色引导光点）                                  |
| 6    | 玩家      | `Player`（player.tscn）                                                          | 0                  |                                                                               |
| 7    | 敌人/假人 | `DummyA` / `DummyB`（dummy_target）、史莱姆（slime.tscn）                        | 0                  |                                                                               |
| 8    | 祭坛      | `Altar`（altar.tscn）                                                            | 0                  | 台座 + 世界空间提示 Label                                                     |
| 9    | 头顶提示  | `TutorialBubble`                                                                 | 0                  | 世界空间，位置=玩家头顶上方，不与地形重叠                                     |

同 z=0 时靠树顺序（后面的盖前面）：背景 → 地形 → 尸体 → 光点 → 玩家 → 敌人 → 祭坛 → 气泡。

### 剑的层级（特殊，M1-12 期间定稿）

- 剑根节点 `z_index = -1`（低于地形/尸体的 0）
- **前提**：背景 `Backdrop` 必须更低于剑（z = -2），否则全屏背景会把剑整个盖住看不见
- 剑的视觉部件（Blade/BladeEdge/Guard/Handle/Pommel）都是 0（relative）→ 实际 -1
- 剑碰撞不受 z 影响（物理独立），拾取照常

## 三、层级规范（以后新形象/物件必读）

1. **加新物件前先想遮挡**：它会和谁重叠？谁该盖谁？
2. **默认全部 z=0**，只靠场景树顺序（后放盖先放）；需要明确遮挡关系时再用 z_index
3. **"插入/嵌进"效果**（剑插地里、碑插土里）→ 物件 z 设负数，并**检查背景/地形是否反而把它盖没了**（背景 z 必须比它低）
4. **"浮在眼前/身上"效果**（武器在手上、特效）→ 物件 z 设正数（≥1），盖住玩家
5. **UI 一律走 CanvasLayer**，不要用大 z_index 硬顶（会被相机/场景缩放干扰）
6. 新物件定稿后**把 z 和遮挡关系补进本表**（两行即可），并在完成报告里说明
