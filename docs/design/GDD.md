# 游戏设计文档（GDD）—— 共生之缚 Symbiont

> 状态：v0.1（M0 草稿框架）｜维护人：游戏设计（组员）｜最终定稿需 2 组确认"待决策清单"后升 v1.0

## 1. 一句话定位

无魔法、蒸汽时代、神明存在的深渊地牢中，一名普通骑士在"献祭获得力量"与"守住人性"之间抉择的类恶魔城 2D 游戏。

## 2. 世界观基础设定

- **无魔法，蒸汽时代，神明存在**。
- **主角**：普通骑士。发现异教徒活跃后独自调查，被察觉后打晕，丢入异教会用来种"人参"的深渊地牢。
- **寄生体**：邪神的精神寄生体（类似古神的低语）。蛊惑主角收集带邪神气息的怪物肢体并献祭，以此给予新能力；代价是改造对应部位（表现上用别的方式代替）。

## 3. 剧情主线

1. 开场：主角被打晕丢入深渊，昏迷后醒来已濒死；
2. 寄生体乘虚而入，蛊惑进行一次"无条件献祭"保住性命 —— **新手教学**（可做"坚决不从→死一次结束游戏"的隐藏结局）；
3. 自下而上探索固定三层地牢；
4. 第二层：异教徒（反派 NPC）vs 工程师（正派 NPC），二选一 → 结局转折点（人与非人的选择）；
5. 第三层：找到出路，击败守门 Boss 后按**献祭次数**结算结局；
6. 探索引导：暗示击败最终 Boss 后回到最开始的地方获取新出现的特殊道具 → 清除异化状态、反咬邪神 → 真结局 HE。

## 4. 核心玩法系统

| 系统 | 说明 |
|---|---|
| 地图 | 固定地图，**仅三层**，自下而上。不用成长路线卡大部分地图探索 |
| 献祭流 | 献祭道具获取更简单更易发现；**必须提示玩家存在别的玩法**，防玩法同质化 |
| 第一层 | 熟悉玩法 + 解锁钩锁（地图探索获得或献祭改造手臂获得）；基础武器与护盾（**不设计防具**） |
| 第二层 | 阵营抉择：帮异教会 → 腿部改造（长按大跳）；帮工程师 → 蒸汽靴（二段跳）。两者跳高相同，仅表现形式不同。武器成长分叉：工程师可升级武器；异教徒放弃武器、用手臂攻击（同模板不同动作） |
| 第三层 | 守门 Boss；结局按献祭次数结算 |

## 5. 结局系统（v0.1 草案，待决策）

| 结局 | 条件 | 说明 |
|---|---|---|
| refuse_die 拒绝（死） | 新手教程拒绝献祭 | 隐藏结局，宁死不屈 |
| human 人类结局 | 击败守门 Boss 且献祭次数 == 1（仅新手那次） | 凭自己的意志走出地牢 |
| transformed 异化结局 | 击败守门 Boss 且献祭次数 > 1 | 发觉自己的身份（发光小精灵式揭示，第一人称视角，最后揭露）；要么自毁，要么被异教徒蛊惑成为新的守门 Boss |
| true_he 真结局 | 击败最终 Boss 后回起点取特殊道具并反噬 | 清除异化，反咬邪神。待决策：人线拿到的特殊道具是否达成更好结局？ |

## 6. 成长路线（数值方向）

- **人类路线**：上限更低、更困难（守住底线本身很难）；"更简单的过程注定到不了好结局"。
- **两个流派**：有攻有防的牢骑士（人类线）vs 超高攻低防的割草怪人（献祭线）。
- 数值表落点：`database/game_data`（balance 表/JSON），代码不写死数值。

## 7. 待决策清单（M0 定稿，2 组拍板）

1. HE 特殊道具与人线"更好结局"的关系（"或许人类线拿到的特殊道具应该达成更好的结局？看情况再商议"）；
2. 献祭计数结局阈值：是否需中间档（如 ≥3 才触发守门 Boss 异化强度）；
3. "拒绝献祭即死"是否保留、是否计入通关统计；
4. 三层地图规模与固定连通方式（回起点引导怎么做）；
5. 双流派数值基线（HP/伤害/攻速/跳跃/钩锁参数）；
6. 存档槽位数量与远程存档策略（自动/手动同步）；
7. UI 风格（Kenney fantasy 边框）与美术分辨率（16/32px）；
8. 音频来源（CC0 音效库选型）；小地图/引导开关（组员想法提到"探索过程加入引导"）。

## 8. 美术风格方向（技术评审不主要看美术，先可玩后美化）

- 基底：Kenney tiny-dungeon 瓦片 + fantasy-ui-borders（CC0，已入库）；
- 角色/敌人/NPC：AI 像素画生成（generate2dsprite 流程），先占位色块跑通玩法，再逐步替换；统一 16/32px 网格；
- 字体：Noto Sans CJK（已入库）。
